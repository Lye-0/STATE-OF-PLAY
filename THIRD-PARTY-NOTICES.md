## Shipped code

| File | Purpose | License |
| --- | --- | --- |
| `public/vendor/prism.js` | Syntax highlighting in the gallery | MIT |
| `public/vendor/jszip.js` | ZIP creation in the browser and Node tools | MIT option; bundled dependency notices below |

The JSZip vendor file matches the official 3.10.1 minified distribution.
Its embedded dependency versions are recorded in that release's
[package lock](https://github.com/Stuk/jszip/blob/v3.10.1/package-lock.json).
JSZip permits either MIT or GPLv3; this project uses the MIT option.

The full source archive includes this document. The production site also
ships the same document at `THIRD-PARTY-NOTICES.md` next to its entry page.
Prism and JSZip support the gallery and export tools; they are not embedded
in the exported standalone UI parts or their preview code.

Build and test dependencies installed through npm retain their own licenses
inside `node_modules/`; that directory is not shipped in the source ZIP.
React is an external dependency of React-format parts and retains its own
license. Applications must handle any third-party dependencies they ship.
