# Studio Selector — 再現仕様

レベルライトと凹み。音響機器のモードセレクター。
音のモードを、選ぶ。

## 視覚
styles.cssのstudio素材、輪郭、文字組み、余白、選択マーカーを基準にする。選択前後と移動途中を確認し、単なる色違いの汎用ボタンに置換しない。非選択ラベルを読めるコントラストに保ち、選択は色・面・線・マークで伝える。Aタイプの素材感と立体的な変化を維持。

## 数と意味
展示の3択は例。itemsの配列から2、3、4、5以上へ変更できること。識別は安定したvalueで行い、固定の33.333%や添字0〜2を使わない。単一選択のradioグループ。ON/OFFスイッチでも同時複数チェックでもない。name/form/required、reset、disabled、ネイティブ入力の意味を保つ。

## 統合
既存プロジェクトのデータと状態へ接続する。value/onValueChangeとdefaultValueを維持。ラベル/アイコン/descriptionを差し替えられるようにする。内部アイコンは装飾、項目内に操作要素を入れない。個体ごとのID・radio名を衝突させない。見た目の3択ではなく2/4/7項目、無効、長い日本語、RTL、複数配置、再配置と取り外しまで検証する。形状・動きは保持し、配置と読み込み先だけ利用先へ適応させる。


## v4.6 TRANSFORM / 現在の表現
小さなルーバーが回り、選んだモードへキーが収まる。
動作の意味・選択値・フォーカスは即時に更新し、演出の終了を待たせない。新しいスタイルと共有のpresentation処理を含める。装飾層を巨大なアイコン・紋章に置き換えない。
文字やフォームの編集面は複製しない。reduced-motionでは安定した最終状態を示し、描画を止める。停止・非表示・取り外し後のRAF/Observer/イベント解除を確認する。
3等分を固定値にしない。2項目・4項目以上、折り返し・縦配置・RTLでも実測した位置へ選択面を置く。内容を入れ替えたりアンマウントして切り替え演出を作らない。
