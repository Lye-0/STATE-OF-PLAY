# Prism Journey — 再現仕様

SIGNATURE / 4.11.0

多面体の節点と分光する接続線が、工程の位置を示す。

## 造形と動き
このパーツの特徴は「FACET / ALIGN」。光の道を、進む。
ソースの各面・レイヤー・輪郭と実寸、陰影、選択／ホバー／フォーカスの変化を保持してください。CSSの色だけを変えた一般的な部品へ置換しないでください。素材の役割を持たない巨大なアイコンを追加せず、他カテゴリと同じ箱型へ統一しないでください。

## 意味と動作
手順のサンプル値は保存・送信しません。beforeNextはPromiseに対応し多重操作を防ぎます。入力中のDOMをステップ移動ごとに作り直しません。外部でcurrentを更新する場合、その判断は利用先が行います。fieldsはtext/email/textareaに対応。

値の確定をアニメーション待ちにしない。実データの文字とクリック位置を装飾の都合で動かさない。外部状態、disabled、複数配置、キーボード、フォームとcleanupを維持してください。AとBで意図する密度・動きは異なります。この部品はタイプAです。

## 表示の一致
styles.cssと依存CSS、各engineとviewを省略せず組み込みます。利用先の配置に合わせて参照を直し、単独／混在、実寸、長い日本語、縮小モーションで確認してください。

## 導入
対象プロジェクトのディレクトリ、パッケージ管理、TypeScriptとCSSの規約を確認し、配布パスは配置例として適応させます。既存ファイルを無条件に上書きしません。参照先を更新し、画面から取り外すときは `destroy()` を呼びます。実行できなかった検証は未確認と明記してください。
