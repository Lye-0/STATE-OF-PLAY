# Tide Tags — v4.9.0 SEQUENCE再現仕様

タグの内部に水が満ち、波の輪郭が揺れて静まります。

## デザインの正本
`styles.css`と依存する`sequence/style.css`・`sequence/skin.ts`を正本とします。形状、素材の厚み、反射、輪郭、文字組みと余白を保ちます。単色の一般的なパーツや大きな先頭アイコンへ置き換えないでください。素材そのものが変化するAタイプです。

## 状態と動き
ホバー・フォーカス・選択は背後の素材面に作用します。テキストは変形させず、実checkboxと独立した削除buttonを維持します。削除時は実inputを即座に取り除き、装飾だけの無操作な残像がほどけて消えます。全体をクリック可能な巨大ボタンにまとめません。
ばねの計算と各素材のSVGを同梱し、一定速度の色変更だけに置き換えません。装飾SVGには文字・tabindex・入力を入れず、pointer-events:none / aria-hiddenを維持します。idleでRAFを残さず、取り外し時はObserver・event・animationを破棄します。動きを減らす設定では状態の変化だけを静止表示します。

## 既存プロジェクトへの導入
配布パスは導入先の指定ではありません。AGENTS.md・コンポーネントの配置・package.json・既存のCSS規約を確認し、利用先の構成へ適応してください。元のデザインは維持します。無条件に既存のApp/mainや同名ファイルを上書きせず、未設定のパスエイリアスを使わず、参照パスを更新してください。対象プロジェクトを参照できなければ、必要な設定とツリーを確認してください。

## 検証
通常／選択／操作中／無効、長い日本語、複数配置、フォーム、ページ数やitemsの変更、縮小モーションを確認します。選択を拒否する親、削除を拒否する親、itemsを更新する親、readOnlyのFormData、最後のタグの削除も確認します。型チェック・ビルド・実ブラウザーの実行結果と未確認事項を区別して報告してください。

## 実装の正本
造形は `sequence/skin.ts`、配置は `sequence/style.css`、動きは `sequence/motion.ts` を参照する。元の階層では `src/shared/foundation/sequence/` にある。配布構成に合わせて参照を更新し、ファイルを省略しない。
