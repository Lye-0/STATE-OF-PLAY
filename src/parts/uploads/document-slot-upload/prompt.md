# Document Slot Upload

中空の横長挿入口へ、実際の選択操作を載せた書類面を差すファイル選択。薄い上線を撤去し、58px高の開いた受け口と、42pxから始まる書類面を接続する。書類が下の受唇へ10px重なり、空いた入口と読む面を明確に分ける。全書類面をnativeファイル選択の同じ操作範囲へ接続し、表示用の偽ボタンを置かない。

- Aタイプ。大胆な素材・形・状態変化を維持。
- 操作の値は直ちに確定。装飾だけを連続的に動かし、文字とクリック領域を安定させる。
- 色違いの既存品に置き換えない。正本CSSの構成、展開面、hover・focus・選択・無効状態を保つ。
- 標準API、キーボード、長い文言、狭幅、reduced motion、forced colors、複数配置と解除を保つ。

## 操作契約
input type=fileと実際のFileListを保持。ファイル名はテキストとして表示。デモの選択処理と実際のアップロードは分離する。
