# Capillary Field — RESPONSIVE / v2.0.0

フォーカスで水の膜が持ち上がり、入力に小さな波が返る。

## 素材と表現
`styles.css`と`responsive-field.css`の形・色・陰影を正本とする。主な表現は `LIQUID / TENSION`。フォーカスと入力イベントによって装飾面だけを動かし、文字・キャレット・input/textarea自体は変形、拡大縮小、フィルター加工しない。標準の編集・選択・Undo・IMEを維持する。大きな紋章や余計なサンプル文字で個性を代用しない。

## 組み込み
既存のTextFieldPropsとTextFieldControllerを維持する。ラベルや本文は利用先へ適応する。素材の処理は値の内容を読み取りも保存も送信もしない。変換中は入力の脈動を止め、確定後に短い余韻を返す。機能部と装飾部を分離し、クリア・エラー・disabled・readOnly・パスワード切替・オートグローを壊さない。複数インスタンスを独立させ、取り外し時には両コントローラーを破棄する。

## 確認
通常・フォーカス・入力・連続入力・変換・確定・blur・エラー・無効・リセット・長文・複数配置を確認する。縮小モーションでは装飾は静止状態。入力が止まればRAFも停止する。アイドル状態で常時アニメーションを回さない。利用先のimportを確認し、CSSと必要な共有ファイルを漏らさない。
