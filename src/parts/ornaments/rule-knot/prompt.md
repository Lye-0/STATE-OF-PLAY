- 名前: Rule Knot
- 方向性: 落ち着いていて、静かな画面にも差し込める。

- 実装: 単独で再利用できるReact / HTML+CSSパーツとして組み立てる。

## 停止状態と持ち出し

Reactでは `paused` を、Vanillaでは `init(element, { paused })` と `setPaused()` を使い、`data-paused` の状態と装飾アニメーションを一致させる。Vanillaの `init.ts` はそのまま実行できる正しいTypeScriptで作り、取り外すときは `destroy()` を呼ぶ。意味を持たない装飾は読み上げ対象から外し、`prefers-reduced-motion` では動きを止める。コード表示・コピー・ZIPでも同じ実装を配布する。
