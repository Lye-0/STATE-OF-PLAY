# Frost Asterisk — ガラススキンの再現・組み込み

既存プロジェクトのディレクトリ構成・実行環境・CSS規約を確認し、配置先を適応させてください。原本は添付ソースです。
このパーツはornamentsであり、専用の展示パネルや背景を本体に追加しません。通常のカテゴリと同じ値・操作を維持します。
外観は `styles.css` と依存する `collection.css` を正本とし、背景だけを透過・ぼかし、文字や入力・画像をフィルターでぼかさないでください。固定の暗いページ背景を強制しません。
Bタイプ。濃いめの面と読みやすさを優先する。
コピー元のパスは配置例であり、導入先で適切に配置を変えて構いません。importとCSS参照を同時に更新し、既存ファイルを無条件に上書きしないでください。
動作の変更・再描画・入力の確定を演出待ちにしません。各操作のアクセシビリティと複数配置、取り外し時の後片付けを維持してください。
前提ファイルがない場合は不足を確認し、型チェック・ビルド・実操作を検証します。未実行の確認は未確認と明示してください。

- 種類: 純粋な装飾パーツ / ornament
- 名前: Frost Asterisk
- 方向性: 落ち着いていて、静かな画面にも差し込める。
- 背景: 深いダークトーン。余白を活かし、周囲は静か。
- 主役: 画面中央に小さめの装飾モチーフを置く。
- 質感: ガラスや金属を直接模倣しすぎず、線と光で上品に見せる。
- 動き: ゆっくり。派手なバウンスではなく、回転、脈動、流れ、反復などを一つだけ明確に持たせる。
- 目的: 機能よりも視覚的なアクセント。ヒーロー、区切り、余白、セクション導入に置ける。
- アクセシビリティ: 装飾なので読み上げ対象から外せる構成にする。
- 実装: 単独で再利用できるReact / HTML+CSSパーツとして組み立てる。
- 禁止: 文字やアイコンを主役にしない。説明的すぎる絵柄にしない。

対象プロジェクトのディレクトリ構造、パッケージ管理、TypeScriptとCSSの規約を確認し、配布パスは配置例として適応させます。既存ファイルを無条件に上書きしません。参照先を更新し、画面から取り外すときは `destroy()` を呼べる構成にします。実行できなかった検証は未確認と明記してください。

公開API・項目データ・値・変更コールバックは使用例と型定義を参照してください。A/Bの外観は添付CSSを維持し、形や色を別スキンの説明から推測して置換しないでください。
