# Schedule Grid Skeleton

曜日の帯と七つの列を、予定表の読込み中の区画として示す。

- Bタイプ。予定表の構造を静かに伝え、読込み状態の分かりやすさを優先する。
- skeletonsの意味とネイティブな操作を保つ。説明のために見た目だけの操作を追加しない。
- 外形、面の配置、縁、文字、選択／展開／入力／無効状態、動きは同梱styles.cssと実装が正本。単なる色違い、別カテゴリの共通意匠へ置き換えない。
- 文字と操作領域を安定させ、キーボード・狭幅・縮小モーション・強制配色・複数配置を保つ。
- 内容や状態は公開APIから接続し、使用例の文言をパーツの制限にしない。
