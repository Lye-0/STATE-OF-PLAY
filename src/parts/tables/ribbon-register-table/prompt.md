# Ribbon Register Table

綴じ帯と選択枚数の短い札を持つ台帳。表題から列見出しへ細い赤紫の帯を引き、セルの本文は明るく固定。

- Aタイプ。大胆な素材・形・状態変化を維持。
- 操作の値は直ちに確定。装飾だけを連続的に動かし、文字とクリック領域を安定させる。
- 色違いの既存品に置き換えない。正本CSSの構成、展開面、hover・focus・選択・無効状態を保つ。
- 標準API、キーボード、長い文言、狭幅、reduced motion、forced colors、複数配置と解除を保つ。

## 操作契約
実体はtable。並べ替え・選択・列幅・検索・ページ送りと列見出しのARIAを保持。横スクロールは表の領域内だけにする。

紙束の外側を走るリボンを二つの通し口で題字紙へ結ぶ台帳。検索面と記録紙は別の面に置き、選択件数の札はリボンと同じ素材で操作のまとまりを示す。

実表・列幅・検索・選択・ページ送りを保持します。非選択でも選択情報の領域を同寸予約し、文字とnative押面を動かしません。狭幅の表は専用の横スクロールで読みます。
