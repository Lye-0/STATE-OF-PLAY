# Tide — 再現仕様 / Type A

## 意図
満ちる、という選択。 水位が上がり、白い浮標がガラスの水槽を渡る。
表現と素材感を主役にするAタイプ。

## 形状・状態
基準サイズは268×124px。ガラス水槽の水位がOFFの底20pxからONの80pxへ上がる。淡いアイボリーの浮標が158px横移動する。OFF/LOWとON/FULLの文字、水位、位置の3つで状態を区別する。

## 動き
同じばねで進捗値--pを駆動。剛性270、減衰23。移動距離は158px。終点付近の減衰を維持。
ON/OFFの文字はaria-checkedに対応させ、スクリーンリーダーへの装飾はaria-hiddenで隠す。ドラッグ途中の進捗と、確定した状態を区別する。

## 守ること
クリック・Enter・Space・左右キー、水平ドラッグ、disabled、controlled/uncontrolled、縮小モーション、複数配置を維持。ラベルの意味は導入先に合わせる。Bタイプでもヒット領域を44px未満に縮めない。
見た目の正本はstyles.css。各層の順序を保ち、サイトのカードや展示ラベルはパーツへ埋め込まない。デモだけでなく単体のOFF/ONも比較する。

## 移設
配布パスは利用先を強制しない。配置を合わせる場合は内部importとCSSの参照を一緒に更新し、既存の同名ファイルは無断で上書きしない。
