# Slate Card — 再現仕様 / Type B

## 意図と形状
情報に、ちょうどいい深さ。 落ち着いたスレート色。数値と文章をすっきりまとめる。
チャコールより少し青いスレートの面。上端の1px反射と10px角丸。発光・ぼかし・追従は使わず、ダッシュボードや設定パネルの情報を読みやすくする。

## 内容とサイズ
幅は親に合わせて100%。高さは中身から決める。基準の内側余白28pxは--sop-paddingで上書きできる。展示用の英語見出しや番号を部品へ埋め込まず、Reactではchildren、通常HTMLでは.sop-surface-contentを利用者の内容に置き換える。

## 動きと依存
CSSだけで動くBタイプ。Canvas、backdrop-filter、常時アニメーション、ポインターの追跡を追加しない。React版は副作用なし、通常HTMLの初期化は任意。

## 確認
styles.cssの面・枠・影を正本とし、装飾はpointer-events:none、本文は上のレイヤー。子のリンクやボタンをカード全体の操作で横取りしない。幅を変更して短文・長文を入れ、複数同時配置を試す。
配布パスは固定配置の命令ではない。導入先の構成に合わせて移設し、CSSと素材の参照先も更新する。
