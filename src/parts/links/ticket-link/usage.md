# Ticket Link
ミシン目と番号帯を持った、細長いチケット。

## リンクとして導入
hrefを持つネイティブa要素です。クリック時にwindow.locationを代入するボタンではありません。文書、ページ内アンカー、mailtoなど実際の移動先をhrefへ設定してください。modifierクリック・中クリック・右クリックメニュー・Enterの標準動作を維持します。
通常HTML版はHTML/CSSだけでも機能します。init(root)はライブラリ共通の任意のライフサイクル窓口で、クリックの横取りや常時処理はありません。

## React / ルーター
childrenで目的がわかるテキスト、hrefで移動先、target/rel/download/aria-currentを標準属性として指定できます。target="_blank"はnoopenerを補い、開き方の説明を支援技術へ付加します。利用先のReact RouterやNext.js Linkへ統合する場合は、返す要素がaになる規約を確認し、aの中に別のaを入れず、クラスと中身の構造を移植します。特定ルーターをこのパーツの必須依存にはしません。

## 見た目と操作
フォーカスリングと縮小モーション・強制配色時の下線を保ちます。ラベルが長くても折り返し、アイコンだけが消えないようにします。閲覧済みの色はデザインの意味とブラウザーのプライバシー制限を考慮し、visitedをJavaScriptで推定しません。リンクに処理中やdisabledを自動付加しません。実行操作にはbuttonカテゴリを使います。
見本の#destinationは例です。導入先に実在する対象へ変更し、存在しないページや空の#へ放置しないでください。
