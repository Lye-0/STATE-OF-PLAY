# Gallery Window — 再現仕様
大きな作品面とエディトリアルな文字を持つ窓。

styles.css/popup-base.css/popup-content.cssの色・寸法・余白・輪郭・文字組みと、examples内の内容構成を正本にする。ベース#e1e3dd、本文#263832、アクセント#495f4d。意図は「余白に、展示する。」。枠だけではなく内部のart / exhibitionの情報表現も維持する。

body外へinnerHTMLで複製せず、実際のdialogをshowModal()で開く。開いた状態のトップレイヤー、後ろのinert、Escape/Tab/Shift+Tab、閉じた後のフォーカス復帰、スクロールロック解除を確認する。上位の詳細モーダルへEscapeが漏れないこと。タイトルとaccessible nameを関連付ける。ネイティブdialogに手動のaria-modalだけを付けた疑似モーダルへ置き換えない。

本文とフッターは利用先のReactNode/HTMLへ差し替え可能。既存のformを入れる場合はsubmit/typeと処理を確認し、閉じた理由で保存・送信したと誤表示しない。デモの値や選択を永続化しない。開閉は利用者の操作に応じて行い、ブラウザーのwindow.openは使わない。外部制御の拒否、連続開閉、別個体同時表示、取り外し、縮小モーションと狭い画面を確認する。


## v4.6 TRANSFORM / 現在の表現
額のシャッターが四辺へ退き、中央の内容が現れる。
動作の意味・選択値・フォーカスは即時に更新し、演出の終了を待たせない。新しいスタイルと共有のpresentation処理を含める。装飾層を巨大なアイコン・紋章に置き換えない。
文字やフォームの編集面は複製しない。reduced-motionでは安定した最終状態を示し、描画を止める。停止・非表示・取り外し後のRAF/Observer/イベント解除を確認する。
