# Nocturne Select — 再現仕様

表紙のような選択肢と、静かな余白。読む時間を選ぶ書棚。
デザインタイプ A。EDITORIAL / NIGHTの素材感を保つ。閉じたトリガーだけでなく、展開した選択肢のアイコン・説明・補助ラベル・選択チェック・フッターまで維持する。

## スタイル
`styles.css`と`select-base.css`が外観の正本。{
  "bg": "#252336",
  "panel": "#262436",
  "accent": "#c6bde3",
  "muted": "#a29bb5",
  "line": "#b7afd52d",
  "radius": "4px"
}

## 動作
実際の選択値をアプリへ返すselect-only combobox。キーボード、無効項目、空リスト、外側クリック、Escape、Tab確定、画面端の配置を維持。開いている間だけ位置を更新し、常時RAFを持ち込まない。ポップアップ内へ別の対話要素を入れない。

## 利用先への適応
選択肢の内容・値・nameは利用先に合わせて差し替える。サンプルの説明は実データではない。構造と装飾は維持し、配布パスはプロジェクトの規約へ合わせる。独立した24個の別実装へコピーせず、共有処理の参照を保つ。
