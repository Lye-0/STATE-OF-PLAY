# Resonance Select — 再現仕様

木目と真鍮色のパネル。アルバムのような選択肢を一曲ずつ。
デザインタイプ A。ANALOG / SOUNDの素材感を保つ。閉じたトリガーだけでなく、展開した選択肢のアイコン・説明・補助ラベル・選択チェック・フッターまで維持する。

## スタイル
`styles.css`と`select-base.css`が外観の正本。{
  "bg": "linear-gradient(130deg,#43372c,#24211f)",
  "panel": "linear-gradient(100deg,#322923,#251f1b)",
  "accent": "#e3bf85",
  "muted": "#b6a591",
  "line": "#715d423f",
  "radius": "9px"
}

## 動作
実際の選択値をアプリへ返すselect-only combobox。キーボード、無効項目、空リスト、外側クリック、Escape、Tab確定、画面端の配置を維持。開いている間だけ位置を更新し、常時RAFを持ち込まない。ポップアップ内へ別の対話要素を入れない。

## 利用先への適応
選択肢の内容・値・nameは利用先に合わせて差し替える。サンプルの説明は実データではない。構造と装飾は維持し、配布パスはプロジェクトの規約へ合わせる。独立した24個の別実装へコピーせず、共有処理の参照を保つ。
