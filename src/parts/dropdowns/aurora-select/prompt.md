# Aurora Select — 再現仕様

光の帯と透ける選択肢。穏やかな色の移ろいをまとったメニュー。
デザインタイプ A。LUMINOUS ATMOSPHEREの素材感を保つ。閉じたトリガーだけでなく、展開した選択肢のアイコン・説明・補助ラベル・選択チェック・フッターまで維持する。

## スタイル
`styles.css`と`select-base.css`が外観の正本。{
  "bg": "linear-gradient(125deg,#1c3533,#1d242e 60%,#2f2641)",
  "panel": "linear-gradient(145deg,#172c29,#222431 70%,#30223a)",
  "accent": "#a4eed7",
  "radius": "18px"
}

## 動作
実際の選択値をアプリへ返すselect-only combobox。キーボード、無効項目、空リスト、外側クリック、Escape、Tab確定、画面端の配置を維持。開いている間だけ位置を更新し、常時RAFを持ち込まない。ポップアップ内へ別の対話要素を入れない。

## 利用先への適応
選択肢の内容・値・nameは利用先に合わせて差し替える。サンプルの説明は実データではない。構造と装飾は維持し、配布パスはプロジェクトの規約へ合わせる。独立した24個の別実装へコピーせず、共有処理の参照を保つ。
