# STATE OF PLAY

**A little switch. A lot of feeling.**

指先で楽しむ、10種類のオリジナル・アニメーショントグル。
黒基調のひとつのページに、異なる素材と仕組みのスイッチを並べたギャラリーです。

## 開く

ZIPを展開し、`index.html` をブラウザーで開いてください。
HTML、CSS、JavaScriptは分離されています。外部通信、npm install、APIキーは不要です。

ローカルサーバーを使う場合（Node.js 20以上）：

```powershell
npm run dev
```

ブラウザーで `http://localhost:5173` を開きます。別のポートを使う場合：

```powershell
npm run dev -- --port 8080
```

## 操作

- **クリック／タップ**：ON・OFFを切り替えます。
- **左右にドラッグ**：位置を直接動かし、離すと近い状態へ吸い付きます。
- **Tab → Space／Enter**：キーボードで選択・切り替え。
- **左／下矢印・Home**：OFF。**右／上矢印・End**：ON。
- **ALL ON／ALL OFF**：10個を順番にまとめて切り替えます。
- **デモ再生**：順番にON・OFFにするループ。もう一度押すか、個別のスイッチに触れると停止します。
- **SOUND OFF**：クリックすると素材ごとの効果音を有効にします。最初は無音です。もう一度押すと無音に戻ります。

スイッチは実際の端末設定などを変更しません。このページ内で完結するインタラクション作品です。

## 実装について

ランタイムの外部依存はありません。画像、Webフォント、録音素材、CDNライブラリーも使っていません。
造形はHTML・CSS・SVG、動的な光や粒子はCanvas 2D、効果音はWeb Audioで実装しています。
フォントは端末のシステムフォントを使用するため、OSによって文字の形が少し異なります。

ばねの位置と速度を保持するため、アニメーションの途中で逆方向に操作しても、その瞬間の運動からなめらかにつながります。
画面外では装飾描画を抑え、タブが非表示になると描画とデモの進行を停止します。
OSの「視差効果を減らす」など、`prefers-reduced-motion` 設定では、移動や連続した装飾アニメーションを止めて即座に切り替えます。
スマートフォンの縦スクロールと横ドラッグを区別します。

ページ上のスイッチはすべて `button` + `role="switch"` + `aria-checked` です。
キーボード操作、フォーカス表示、状態読み上げに対応しています。
音はユーザーが明示的に有効にするまで再生しません。

## 検証・ビルド

```powershell
npm test
npm run build
```

`npm test` はNode.js標準機能のみを使った14項目のテストです。
`npm run build` で生成された `dist/` の内容を、静的サイトのホスティング先に置けます。
GitHub Pagesなどでプロジェクト配下へ置く場合も、相対パスを使っています。

閲覧用に単一のHTMLファイルも作りたい場合：

```powershell
npm run preview:build
```

生成される `preview.html` は**閲覧用コピー**です。元のプロジェクトの分離構成は変更しません。

## カスタマイズ

- 色や余白：`css/base.css`
- 個別のスイッチの質感：`css/objects.css`
- 初期状態、ばねの硬さ・減衰：`js/motion.js` の `OBJECTS`
- 装飾の描画：`js/objects.js`
- 効果音：`js/audio.js`
- デモの間隔：`js/app.js` の `demoStep()`

初期状態を変える際は、`motion.js` の `initial` に加え、`index.html` の対応する `aria-checked` と `--p` も合わせて変更してください。
