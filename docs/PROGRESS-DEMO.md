# 進捗表示のデモ再生

「進捗表示」カテゴリの一覧に、トグルと同じ見た目の「デモ再生／デモ停止」ボタンを表示する。再生中は現在フィルターで表示されている全進捗表示へ周期値を設定し、パーツ順に位相をずらして素材の反応を同時に見せる。

再生は480ms間隔で値を巡回し、停止時は現在値を保持する。進捗コントローラーの`setData`を使うため、ネイティブprogressと各素材表示が同じ値を受け取り、配布コンポーネントや外部データは変更しない。トグル再生とは別タイマーだが、カテゴリ切替・検索による描画更新・詳細表示・ページ非表示・ステージ上の手動操作では共通停止処理が両方を止める。

確認は`npm run test:progress-demo`。24表示の初期化、位相をずらした値の巡回、停止後の値保持、手動操作での停止、カテゴリ切替での停止と表示切替を検査する。
