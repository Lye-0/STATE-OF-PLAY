# v4.1 — Type A / Atelier

v4.0.0再構築版の表現重視パーツを、既存のトグルやタブと同じく「輪郭・材質・構造・動き」を持つUIへ改訂した版です。総数は25カテゴリ・564種類のままです。

## 変更しないもの

- v4より前の280パーツ：本体2,800ファイルを元ZIPと照合し、完全一致。
- v4のBタイプ97種類：外観の宣言値・マークアップ・操作実装を維持。
- ローダー24種類：従来の造形とアニメーションを維持。

ただし、v4のBタイプとローダーにあった「カンマ以降のCSSセレクターが他パーツにも作用する」不具合を修正しました。113スタイルシート、737のセレクター分岐を各パーツ内へ限定しています。宣言値は変更していません。単独表示と全コレクション混在時の描画を揃えるための修正です。対象パーツのバージョンは4.0.1です。

パンくずの途中階層メニューが初回操作前に表示される不具合も修正しています。公開APIの変更はありません。

## 開発・持ち出し

新しい構造は次の共有ファイルで管理します。

```text
src/shared/foundation/
├─ base.css                 # 既存の機能・基礎スタイル
├─ atelier.css              # Aタイプ共通の構造と状態
└─ materials/
   ├─ aurora.css
   ├─ mercury.css
   └─ ...                   # 計16素材
```

パーツの `styles.css` は必要な素材だけを `@import` します。独立デモ、TSX／JSX／TS／JS、導入向け／元の構成、コード表示、パーツZIPは従来の依存解決から同じCSSを取得します。共通ファイルを各パーツの開発用フォルダーへ複製しません。標準フォントとCSS内のSVGを使用し、新しい画像・フォント・実行時ライブラリへの外部アクセスは追加していません。

再現プロンプトには新しい材質・造形の指定と必要CSSを追記しました。共有スタイルを編集した場合は、混在表示と単独の持ち出し表示の両方を確認してください。

```sh
npm run typecheck:app
node --experimental-strip-types --test tests/atelier.test.ts
npm run test:atelier
```

`npm test` と `npm run verify`、GitHub Actionsにも新しいチェックを組み込んでいます。実際に今回実行できた範囲は [ATELIER-VERIFICATION.md](ATELIER-VERIFICATION.md) を参照してください。
