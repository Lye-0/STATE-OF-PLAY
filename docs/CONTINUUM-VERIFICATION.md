**進捗**：16種すべて実際のネイティブprogressが同期的に変わり、装飾SVGが後から追従。負数、小数、退化した範囲、未知の進捗、停止、無効化、縮小モーション。100%の円形経路が消失しないことも確認。

**ローダー**：新16種のCSSアニメーションと擬似要素の停止、画面外・非表示・縮小モーション、Bの寸法と明暗背景。状態テキストを毎フレーム書き直さないこと、取り外し後のObserver解除。停止と処理成功を混同しません。

**共通**：58種を幅320 / 390 / 768pxと長い日本語で表示し、ページ横あふれなし。強制配色、装飾にフォーカスが入らないこと、重複しないSVG識別子、停止後のRAF残留なし。全604スキンを読み込んだ状態でも、新58種の主要スタイルが単独表示と一致。

実行環境はLinux / Node 22.16.0 / TypeScript 5.8.3 / 実Chromium 144です。
Playwrightは環境にインストール済みの1.57.0-beta-1764944708000を使いました。

クリップボードのOS許可・保存先のOSダイアログを今回実機操作したわけではありません。コード表示と保存用本文は照合しています。

## 配布ZIP

リポジトリの `npm run package` は許可したソース・設定・テスト・ドキュメントだけを集め、生成したZIPをCRCとSHA-256で読み直します。
`.git`、node_modules、.test-output、.env、実行時キャッシュ、単一HTMLプレビューは配布しません。元のフォルダー構造は保持します。
さらに独立したPython zipfileで全エントリを再読し、全体ZIPの再展開と、v4.7.0へ差分を適用した結果の一致を確認して渡す工程です。
CRC/SHA-256は内容の整合性確認であり、OSによる警告が出ない保証やマルウェア検査ではありません。
