# SIGNATURE の統合 — v4.11.0

受領した差分はv4.10.0の604パーツを基点にしています。このリポジトリはv4.10.10で、重複のため削除したPaper Loaderを除く603パーツでした。既存の削除とv4.10.1〜v4.10.10の修正を維持し、新規96パーツを追加したため、統合後は**31カテゴリ・699パーツ**です。受領元の「700パーツ」は[元の検証記録](SIGNATURE-VERIFICATION.md)の値です。

6カテゴリに各16パーツ（A10・B6）、計96フォルダ・960のパーツ本体ファイルを追加しました。共有処理は`src/shared/signature/`、一覧と詳細の操作は`src/app/signature-preview.ts`です。既存の`src/parts/`内の追跡済みファイルには変更を加えていません。受領差分のアプリ・カタログ・CIをそのまま上書きせず、必要な追加箇所を現在の実装へ統合しました。

カタログは96件を既存レジストリへ追加し、カテゴリ定義・型・生成時の検証を拡張しました。`buildCatalog(root, onlyIds)`を残したため、詳細を開いたパーツだけのソース取得が引き続き可能です。ギャラリーは選択カテゴリの実装だけを読み込み、最初は24トグルのみを表示します。新作の詳細では状態の切替、4形式×2配置のコード・使い方・AI用プロンプト・個別ZIPを提供します。既存の起動表示、カテゴリ選択、デモ再生、日時選択の独自UIは維持しています。依存パッケージは変更していません。
