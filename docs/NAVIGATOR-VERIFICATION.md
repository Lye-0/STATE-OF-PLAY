## 環境と制約

Linux / Node.js 22.16.0 / TypeScript 5.8.3 / 実際のシステムChromiumを使用しました。実行用Playwrightは環境にインストールされた1.57.0です。プロジェクトが指定する1.63.0を取得できた、という検証ではありません。

npmレジストリとCDNは名前解決に失敗し（EAI_AGAIN）、依存一式を新規インストールできませんでした。`agent-browser` コマンドも存在しません。ローカルHTTPへの通常のナビゲーションは管理されたブラウザーポリシーにより ERR_BLOCKED_BY_ADMINISTRATOR となりました。設定の解除やポリシー変更はしていません。

そのためブラウザー確認は、`SOP_TEST_MODE=offline` の明示的なテスト用文書に**実際の元ソースを変換したコードとCSS**を読み込む方法です。`testBundle`はテスト用CommonJS変換器であり、Viteの代用品として配布するものではありません。実際の配布JSの検証もオフライン変換器を通しているため、HTTPのES Modulesローダーを検証したという意味ではありません。

**実Viteの開発サーバー・本番ビルド・HTTP配信、公式React本体／型定義による新作React版の実行と完全な型チェック、npm audit、GitHub Actionsの完走は未確認です。** React版はソース変換と依存関係の閉包を検査しました。既存の環境にあったReact16は必要なAPIを満たさないため、代わりに使ったり成功扱いにはしていません。

`typecheck:react`と`typecheck:tools`は実際に実行し、React／Viteの依存不足で失敗しました。失敗ログも含めています。手製の型定義で成功扱いにはしていません。

IMEの確認は合成compositionイベントです。Windows/iOSの実IME、VoiceOver/NVDA実機、Safari/Firefox、Windows Explorerの展開警告・Defender判定は未検証です。

## 再実行

通常のネットワークが利用できる開発環境では、標準の依存をインストールして次を実行します。SOP_TEST_MODE等のテスト用環境変数は通常の利用には不要です。

```powershell
npm install
npx playwright install chromium
npm run verify
npm run package
npm run dev
```

新規領域だけを確認する場合は `npm run test:workbench` と `npm run test:workbench:gallery` です。後者は全カタログのコード生成も行うため時間がかかります。

## 機能上の境界

- 検索はローカル配列または外部の非同期関数に接続します。サーバーや検索履歴保存を同梱したものではありません。
- コマンドのショートカット表示はヒントであり、全キーを勝手にグローバル登録しません。全体のCtrl/Cmd+Kは明示的に有効化したものだけです。
- コンテキストメニューは対象領域に限定し、階層は同じパネルでのドリルダウンです。通常の右クリックやタッチ長押しを全ページで妨害しません。
- ナビゲーションのhrefは実URLへ差し替えます。利用先のルーターは同梱しません。
- テーブルは読み取り中心のネイティブtableです。セル編集・仮想スクロール・列ドラッグ並べ替え・複数列ソートはありません。formatの文字列はエスケープし、任意HTMLを実行しません。

`navigator-checks/`に成功・失敗の実行ログを収録しています。
