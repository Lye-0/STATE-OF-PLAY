# ローダーの回転と重複整理 — v4.8.1

## 対象

Nixie LoaderとCeramic Loaderの2番目の正方形にある小さな四角が、1周の継ぎ目で突然位置を変えていました。Paper LoaderはCeramic Loaderと同じマークアップ・回転機構・ほぼ同じ造形で、主な違いが色・角丸・影だけでした。表現重視のCeramicを残し、PaperのIDと本体を削除しました。パーツは603、ローダーは39です。既存の順序番号は変更しません。

## 原因と修正

2番目の正方形は静止位置に `rotate(45deg)` を指定していましたが、回転アニメーションには終点の `rotate(360deg)` だけがありました。逆再生ではCSSが45度と360度を補間し、周回の継ぎ目で約47度跳んでいました。

共有CSSに45度から405度へ1周するキーフレームを追加し、NixieとCeramicの2番目の正方形だけに適用しました。両端は同じ向きです。その他のローダーの回転と縮小モーション・一時停止処理は維持しています。

両パーツの `styles.css`、`usage.md`、`prompt.md`、メタデータのバージョンを更新しました。詳細画面のソース、使い方、AIプロンプト、配布ZIPは正本から生成されるため同じ内容です。削除したPaperはカタログや配布対象に残しません。

## 検証

- 変更前に実Vite / Edgeで3種類の2番目の正方形を3秒ずつ計測し、各周回の最大角度変化が約47度であることを確認しました。
- 変更後のNixie/Ceramicを1周以上計測し、最大のフレーム間変化は約5度／約3度でした。周回境界の前後1msを明示して比較すると、どちらも差は約0.31度でした。
- 全16組（2パーツ×4形式×2配置）の配布ソースに新しいCSSが含まれ、コード込み／仕様のみのプロンプトとZIPが生成元に一致することを確認しました。
- 実ギャラリーで総数603、ローダー39、Paperなし、Nixie/Ceramicの詳細コードとプロンプトを確認しました。
- `node --experimental-strip-types tests/loader-orbit.browser.ts` をCIに追加しました。アプリ・React・ツールの型チェック、本番Viteビルド、全単体テスト186件が成功しました。CONTINUUMのギャラリー検証7項目と、共有CSSの混在表示を含む既存ブラウザー検証20項目も成功しました。

添付動画はブラウザーのローカルファイル制限で開けませんでした。静止画像、現在のCSS、実コンポーネントの角度計測を根拠に修正しています。制限を迂回する操作はしていません。

ルートの `RELEASE-MANIFEST.json` は以前のv4.8.0配布記録です。現在版の全体ZIPを生成すると、その中にv4.8.1の新しいマニフェストが入ります。
