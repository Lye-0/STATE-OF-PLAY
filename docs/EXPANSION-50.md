# 50種類への拡張

37カテゴリそれぞれの A/B 合計を50種類に拡張した。追加730種類は A 547 / B 183。登録総数は1,850種類（A 1,388 / B 462）。既存の識別子と Liquid Glass のコレクションは維持している。

新規部品には `EXPANSION-50` タグを付けた。件数の正本は `src/catalog/registry.json` と各部品の `meta.json`。TS/JS/TSX/JSX および portable/original は同じ部品の配布形式であり、件数には重複計上しない。

A は機構、素材、輪郭、内部配置、動きを中心に設計した。例は差動式トグル、紙の重なりを使う入力欄、貨物ハッチ型アップロード、縦の章立てを持つウィザード、伸縮するローダー。B は操作対象と選択状態を明確にし、余白と静かな素材感で使いやすさを優先した。ネイティブ入力、キーボード操作、既存のライフサイクルは共有実装を利用する。

## 検証

- `npm run typecheck`：アプリ、React、ツール。
- `npm test`：既存回帰テストと追加部品の登録・配布・ライセンス・構文・重複検査。
- `npm run build`：全1,850種類を含む本番ビルド。
- `npm run test:expansion-50`：追加730種類の一覧操作、狭幅、React StrictMode の4形式、ギャラリーに依存しない JavaScript の2配置。ローダーと装飾の実アニメーション、一時停止、reduced motion も検証する。

ブラウザ検査のカテゴリ指定には `SOP_EXPANSION_CATEGORIES=toggles,buttons` を使用できる。CIでは指定せず全カテゴリを検査する。既存の歴史的コホートを対象とする回帰テストは元の識別子集合を維持し、新規部品は専用検査と全体配布検査の両方で扱う。

画像付きレビュー成果物と作業用スクリプトはリポジトリ外に保存する。ライブラリの実行時には不要。
