# 初回表示のNixie Loader

初回表示・再読み込みで、ギャラリーCSSの適用前に未スタイルのHTMLが一瞬見えることがありました。v4.9.2では、初期カテゴリの描画が終わるまで起動表示を使います。パーツ数やカテゴリ別読み込みの構造は変更していません。

このサイト本体はViteとVanilla TypeScriptです。詳細画面の4形式から選ぶなら**Vanilla TS**です。起動表示は `src/parts/loaders/nixie-loader/prompt.md`、`markup.html`、`styles.css`、`src/shared/foundation/base.css`を参照し、Nixieの琥珀色と二番目の正方形の45→405度の連続回転を保っています。

通常のパーツと違い、起動表示はJavaScriptと外部CSSより先に描く必要があります。そのため `index.html` にNixieの表示構造と必要最小限のCSSを置き、`src/app/gallery.ts` が初期カテゴリの描画を終えてから表示を切り替えます。利用者に待ち時間を追加するための固定遅延はありません。取り外しの短いフェードだけを使い、縮小モーションの設定では停止します。12秒経っても起動しない場合は現在のURLを保つ再読み込みの導線を表示し、JavaScript無効時は説明文を表示します。

起動表示の造形を変える場合は、Nixie本体の正本と起動用CSSを一緒に確認してください。Nixieパーツ自体を変更する場合は、従来どおりパーツ詳細のコード・使い方・AI用プロンプト・配布ZIPにも反映します。

検証は `npm run test:site-boot` で行います。実ブラウザーでアプリのモジュールを遅らせ、初回表示とリロードの両方で未スタイルのページが見えず、Nixie表示から24件の完成したカードへ移ることを確認します。390px幅、縮小モーション、JavaScript無効時、モジュールの読み込み失敗時も確認します。
