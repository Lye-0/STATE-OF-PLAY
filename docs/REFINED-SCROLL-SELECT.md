# v4.3.0 — 比率・面・動きで作るAタイプ

対象はスクロールバー16種類・プルダウン16種類のAタイプです。総数は25カテゴリ・564パーツのままです。Bタイプと他カテゴリのパーツ本体は変更していません。

## スクロールバー

巨大な筐体・口金・マークを縮小するのではなく、細い面として輪郭と陰影を再設計しました。可視レール9〜12px、可視つまみ15〜18px。操作領域は別に34px（粗いポインターでは44px）を確保します。背景のボタンや本文に重ねず、ガター内に収めます。横向きの場合は高さに対応します。

つまみの長さと位置は元のスクロール計算を使います。影・反射・表面だけが反応し、スクロール位置をばねで遅延させません。カスタムCSSで寸法を変える場合は、見える部分だけでなく本文との距離とタッチ領域も確認してください。

### 進んだ位置をレールへ表示する8種類

Capillary / Aurora Thread / Cable / Tideglass / Ember Rail / Light Leak / Phosphor / LED Rail。

`--sop-scroll-progress`を使い、始点側と先の部分で透明度・質感・光が変わります。読了履歴の保存ではなく、現在のスクロール位置を示す表現です。上へ戻ると表現も戻ります。

残り8種類は、同じ演出を強制せず、サテン仕上げ、重なる干渉線、細い多面体、紙の折り返し、つまみ周辺のレール変形などを使います。横向き・RTL・内容の増減でも、見える造形を実際のつまみへ合わせます。

## プルダウン

文字を主役にしたコンパクトな候補一覧です。大きな自動アイコン・装飾用イニシャルをAタイプの標準から外しました。単行候補は46pxを基準に、説明や長い文字列があれば自然に高さが増えます。フィールドはmin-height 62pxです。

静止した選択済みチェックと、ホバー／キーボードで移動する候補背景を分離しました。候補の文字自体は動かしません。面の移動は約230ms、展開は約240msが基準ですが、アニメーション完了を待たずに選択できます。

- 背景面: Optic、Orbit、Ceramic、Fjordなど。行から行へ滑る面。
- 光と透明層: Aurora、Glasshouse、Nocturneなど。ポインター位置で光が変わる。
- 紙の展開: Atelier、Archive、Relic。紙の層や下端の影。
- 文字組みと下線: Spectrum。文字幅に合う線が動く。
- 浅い金属面／帯: Resonance、Transit。持ち上がるキーや区切りの表現。

各スキンは専用の背景・輪郭・開き方を持ちます。単なる色違いではありません。

### Reactの追加プロパティ（後方互換）

| Props | 意味 | Aタイプの初期値 |
| --- | --- | --- |
| `autoIcon` | アイコン未指定時にラベル先頭の文字をアイコンにする | `false` |
| `showHeading` | 候補一覧の補助見出しと件数を表示 | 5種類は`true`、残りは`false` |
| `showHints` | 下部の操作ヒントを表示 | `false` |

`items[].icon`を指定すると、`autoIcon={false}`のままでも約20pxの小さいアイコンを表示できます。アイコンなしの場合に空のアイコン枠は残しません。小さい記号・文字向けであり、複雑な任意UIは既存の`renderOption`へ渡します。候補内へ別の操作ボタンを入れないでください。

```tsx
<NocturneSelect
  label="並び順"
  items={[
    { value: 'updated', label: '最近更新した順' },
    { value: 'name', label: '名前の昇順' },
    { value: 'created', label: '作成日の新しい順' },
  ]}
  value={sort}
  onValueChange={setSort}
  showHeading={false}
  showHints={false}
/>
```

コンポーネントに展示用の書籍名・行先・単位を固定していません。通常の設定値に差し替えても、同じ造形・選択動作を使えます。

Vanilla版は不要な`.sop-select-icon`を入れず、必要な項目だけアイコン要素を配置します。見出し・操作ヒントも省略できます。構造の変更後は既存の`refresh()`を呼んでください。

## 動きの実装

新しい`src/shared/select-motion.ts`は、Aのopt-inクラスを持つときだけ動作します。候補の位置・サイズをpopupの内容座標としてCSS変数へ渡し、擬似要素の面を動かします。Reactが管理する候補リストへDOMを挿入しません。

行の高さ、グループ見出し、内部スクロール、候補の増減を考慮します。Pointer / Scroll / Resize / Mutationをきっかけに更新し、常時RAFループやポーリングを使いません。閉じる・取り外す際はRAF、タイマー、observer、イベントを解除します。

共有CSSの後に同じ共有CSSが再読込されても色・幅が戻らないよう、固有スキンに3クラスの詳細度を使用します。オプトインクラスとスキンクラスを取り除かないでください。

## 配布と制約

TSX / JSX / TS / JS、導入向け／元の構成のどちらでも、実際の依存関係から`select-motion.ts`等を同梱します。コード表示、コピー、ZIP、AI用プロンプトは同じソースを使います。プロンプトには新しい幅・面・動き・任意の情報構造を記載しました。

縮小モーション時はアニメーションを省略して最終位置へ反映します。ホバー不可の端末でもタップと選択が使えます。強制配色時は選択状態をシステム色で示し、スクロール領域は標準スクロールバーへ戻します。

色・明暗差・スクロールバーを含む実機の使用感は、配置先の背景・拡大率・入力機器でも確認してください。Windows/iOS実機、Safari/Firefoxでの動作とReact指定環境の再検証は今回の実行範囲外です。
