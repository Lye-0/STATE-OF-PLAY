# Mercury Selector の光沢移動

v4.10.8では、セグメントの「Mercury Selector」で選択を隣へ移す際に、鏡面の光が強く回りすぎる問題を抑えました。

## 原因

共有のTRANSFORM表現では、選択移動中の速度を金属グラデーションの角度へ最大90度、光沢筋へ最大60度反映していました。加えて、選択片を横へ19%伸ばし、縦へ10%縮めるため、金属面全体が大きく変化して見えていました。

## 変更

共有CSSの既定値は維持したまま、素材ごとに動きの振幅を指定できるようにしました。Mercury Selectorだけに小さな振幅を設定し、他のTRANSFORMパーツの見た目は変わりません。

| 動き | 変更前 | Mercury Selector |
| --- | ---: | ---: |
| 金属グラデーションの回転 | 最大90° | 最大16° |
| 光沢筋の角度変化 | 最大60° | 最大14° |
| 光沢筋の強さ | 0.8 | 0.28 |
| 横方向の伸び | 19% | 3.5% |
| 縦方向の縮み | 10% | 2.5% |

選択値、ラジオ入力、フォーカス、キーボード操作の処理は変えていません。Mercury Selectorの説明、使い方、AI用プロンプトも穏やかな反射の仕様に合わせました。詳細画面と配布コードには、パーツCSSと共有のTRANSFORM CSSの両方が含まれます。

## 確認

実ChromiumでMercury Selectorの右隣への選択移動を実行し、値が即時に変わること、金属面の角度変化が16度以内に収まること、全24セグメントのラジオ操作と詳細画面が保たれることを確認しました。選択コンポーネントの単体テスト9件、アプリ・React・ツールのTypeScriptチェック、本番Viteビルドも成功しています。全単体テストと4形式すべてのReactマトリクスは完走していません。
