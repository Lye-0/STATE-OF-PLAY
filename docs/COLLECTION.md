## Liquid / Fold / Prism の状態表示

| パーツ | OFF | ON |
|---|---|---|
| Liquid | `OFF / STILL`。落ち着いた低彩度のレンズ | `ON / FLOW`。水色の光と流れが戻る |
| Fold | `OFF / FOLDED`。紙が畳まれ、空の状態ドット | `ON / UNFOLDED`。紙が伸び、温かい色と点灯ドット |
| Prism | `OFF / DORMANT`。低彩度の休止した結晶 | `ON / REFRACT`。虹色の反射と光線が広がる |

装飾テキストはパーツ自身に含め、ギャラリーの状態表示がなくても読めるようにしています。スクリーンリーダーへはbuttonの `role="switch"` / `aria-checked` と用途を表すラベルで伝えます。

## 配布

すべてのパーツでTSX / JSX / TS / JS、導入向け / 元の構成、通常ソース / テキスト保管版を選べます。コード・プロンプト・使用例・配置マニフェストを同じ生成元から作ります。Bの軽量な描画方式もプロンプトへ記載し、導入時に不要な装飾やライブラリを追加しないようにしています。

サンプルの文章・数値・ボタンの挙動はギャラリー用です。カード本体は好きなchildren/DOMに置き換えられます。
