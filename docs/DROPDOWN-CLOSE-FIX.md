# プルダウンの閉じ際の表示修正（v4.10.2）

Kinetic系12種類では、コントローラーが閉じた元の候補パネルを、約210msの退出演出のためにポップオーバーへ再表示していました。`hidden`と`aria-hidden`を設定してもCSSが`display:block`へ戻しており、実画面で候補一覧が一瞬見えました。

`src/shared/kinetic-select.ts`は候補パネルを閉じたままにし、短い反応をトリガーにだけ残します。`src/shared/kinetic-select.css`の非表示を上書きする規則を削除しました。開く際の造形、ホバー面、値の即時確定、キーボード操作は維持します。12種類の使い方とAI用プロンプトにも閉じる際の契約を反映しました。

修正前、実Edgeのギャラリーで36種類を調べると、12種類が閉じた直後に`hidden=true`なのに`display:block`かつ`:popover-open`でした。他24種類は即時非表示でした。修正後の`npm run test:dropdown-close`は36種類を実クリックで開閉し、閉じた直後・次の描画フレームに候補が表示されないことと、代表例のEscape操作を確認します。さらに12種類×4形式×2配置の96配布構成について、閉じ際の共有処理・CSSと最新AI用プロンプトが含まれることを照合します。`npm run test:kinetic`では開く動き、素早い再開、選択、スクロール、縮小モーションを確認します。
