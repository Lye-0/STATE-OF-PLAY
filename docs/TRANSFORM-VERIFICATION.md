## 環境と未確認事項

Linux、Node.js 22.16.0、TypeScript 5.8.3、実Chromiumを使用しました。ブラウザーは環境にあるPython Playwright同梱のNodeドライバーを使用しています。プロジェクト指定のPlaywrightを新規取得したものではありません。

npmレジストリへの接続は名前解決（EAI_AGAIN）で失敗しました。Viteと指定のReact/型定義を取得できないため、**実Viteのbuild/HTTP配信、今回変更したReact版の実行、公式型定義一式によるReact型チェック、npm audit、GitHub Actionsの完走は未確認**です。

`typecheck:tools`もViteの型がないため成功していません。エラー一覧を`transform-checks/typecheck-tools-unavailable.txt`に保存しました。仮のVite/React型定義や代替ランタイムを使って成功したようには扱っていません。

ブラウザーは明示的なオフライン用fixtureを`setContent`し、実際のソースからコンパイルしたJSとCSSを読み込みました。ギャラリー確認でも同じ元ソース・カタログ・詳細画面を使用していますが、Viteでの配信確認ではありません。ブラウザーの管理ポリシーを変更していません。

React向けファイルは実装・依存解析・TSX→JSXの変換確認までです。JSXの変換成功はReactでの型チェックや実行成功を意味しません。

Windows実機、iOS/Safari/Firefox、支援技術の実機読み上げは未検証です。スクリーンショット用に拡大/縮小した画像と実寸の操作テストは区別しています。

## 再実行

```sh
npm install
npx playwright install chromium
npm run verify
```

`npm run test:transform`と`npm run test:transform:gallery`を新設し、通常はVite HTTPで実行します。検証環境だけ`SOP_TEST_MODE=offline`を明示しました。環境変数がない通常の開発でオフラインへ自動的に切り替わることはありません。

## ログと配布

実行ログは`docs/transform-checks/`に収録しています。ルートの`RELEASE-MANIFEST.json`は配布ファイルのSHA-256です。CRC/ハッシュ検証はファイルの整合性検査であり、ウイルス判定やWindowsで無警告になる保証ではありません。
