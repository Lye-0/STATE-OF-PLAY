# NAVIGATOR の統合 — v4.12.0

受領差分はv4.11.0の700パーツを基点にしています。このリポジトリのv4.11.0は、重複のため削除したPaper Loaderを除く699パーツでした。既存の削除と、v4.10.1以降の修正・カテゴリ別遅延読み込みを保ち、新規88パーツを追加したため、統合後は**36カテゴリ・787パーツ**です。受領元の「788パーツ」は[元の検証記録](NAVIGATOR-VERIFICATION.md)の値です。

検索バー20、コマンドパレット16、右クリックメニュー16、ナビゲーション20、テーブル16の計88フォルダ・880のパーツ本体ファイルを追加しました。共有処理は`src/shared/workbench/`、展示専用の操作は`src/app/workbench-preview.ts`です。既存の`src/parts/`内の追跡済みファイルには変更を加えていません。受領差分のアプリ・カタログ・CIを上書きせず、必要な箇所だけを現行構成へ統合しました。

カタログでは88件を既存レジストリに追加し、カテゴリ定義・型・生成時検証を拡張しました。`buildCatalog(root, onlyIds)`を残したため、詳細を開いたパーツだけの配布ソース取得が引き続き可能です。初回画面は24トグルのみを読み込み、新しい5カテゴリは選択時に読み込みます。新作の詳細には状態操作、4形式×2配置のコード・使い方・AI用プロンプト・個別ZIPを接続しました。依存パッケージのバージョンは変更していません。

受領差分の元記録とログは[NAVIGATOR-VERIFICATION.md](NAVIGATOR-VERIFICATION.md)に保持しました。そちらの実行結果とパーツ数を、この統合先で再実行した結果として扱いません。`PATCH-MANIFEST.json`も受領差分の原記録であり、統合後の全体ZIPはこのリポジトリから再生成します。
