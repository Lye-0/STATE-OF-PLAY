# 配布方針

このチャットでの受け渡しは、差分ファイルや個別の.jsファイルではなく、
**リポジトリの作業ファイルを丸ごと置き換えられる全体ZIP**を使用します。

全体ZIPには、表示できるビルド済みサイトだけでなく、編集用ソース、
ビルド・テスト・設定、パーツの各形式のソース、説明書、ライセンスを含めます。
ただし、Gitの内部履歴 `.git/`、再インストールできる `node_modules/`、
環境固有の秘密情報やキャッシュは含めません。

再作成コマンドは `npm run package` です。
ファイル本文と元の拡張子を保った通常のZIPであり、自動実行・保護の無効化は行いません。
全体ZIPの内容だけで再ビルドできます。以前の会話の単一HTMLや差分ファイルへの参照は不要です。
