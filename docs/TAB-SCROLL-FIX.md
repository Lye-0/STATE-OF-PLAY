# タブ列の横スクロールバー（v4.10.3）

Aurora TabsではNotesを選ぶと、3項目のボタンは枠内に収まっているのに、装飾のスクロール可能幅が4〜7px増えて標準の横スクロールバーが現れました。項目を7件に増やした場合は実際の横スクロールが必要ですが、既定の矢印やつまみは各デザインから浮いていました。

`src/shared/selection-indicator.ts`は実際のタブボタンの範囲で横スクロールの要否を測ります。装飾だけの余分な幅では横スクロールを隠し、ボタンがあふれた場合だけ有効にします。サイズ変更・項目の追加削除・縦横切り替えでも再測定し、不要になったスクロール位置を戻します。

`src/shared/selection-base.css`は細いレールとつまみを定義し、標準の矢印を消します。24種類の`styles.css`がそれぞれの素材色を指定し、背景色・角の形も既存のデザイントークンから受け取ります。Ribbon Tabsも横向きの項目増加時にスクロールできるようにしました。縦向きは従来の配置を維持します。

24種類の使い方・AI用プロンプトと、ギャラリーが生成するプロンプトを同時に更新しました。配布コードと各形式のパーツZIPは同じ共有ソースから生成されます。`npm run test:tab-strip`でAuroraの3項目、全24種類の項目増加時、縦向き、詳細コード・プロンプト、PC／モバイル幅を検証します。
