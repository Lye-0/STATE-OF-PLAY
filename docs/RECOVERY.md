# v4.0.0 再実装と配布の記録

## 何を再開したか

以前の会話ではv4.0.0の実装完了・ZIP作成が案内されましたが、該当ZIPと追加ソースは保存されていませんでした。
この版は、保存されていたv3.8.0全体ZIPのソースを土台に、追加予定の13カテゴリ・284パーツを**新しく実装し直した版**です。
失われた作業データの完全復元や、以前の参考画像と同一のデザイン・APIを保証するものではありません。

## 保持した範囲

元の12カテゴリ・280パーツを保持しています。元ZIP内のパーツ本体 2800 ファイルをバイト比較し、変更・欠落がないことを確認しました。
追加後は25カテゴリ・564パーツです。照合元ZIPのSHA-256とカテゴリ内訳は `RECOVERY.json` に記録しています。

## 新しく実装した範囲

スライダー、ラジオ／選択カード、コンボボックス、通知、ツールチップ／ポップオーバー、進捗表示、ローダー、
ファイル選択、日時選択、ページ送り、パンくず、タグ／チップ、数値入力。
Aタイプ187・Bタイプ97の追加です。ラベル・候補・値・設定は公開props/APIから利用先のプロジェクトへ接続します。

## 納品の違い

今回は実在する `scripts/package.ts` を実行してZIPを作り、そのZIPをPythonのzipfileでも開き直します。
`RELEASE-MANIFEST.json` は収録ファイルの実バイトから作られます。存在しないパスや、画像だけをソースとして渡す方式ではありません。
ZIPの整合性とアプリの動作検証は別です。実行範囲・失敗・未確認は `FINAL-VERIFICATION.md` を参照してください。
