## 具体的な検証

ラジオは16素材、確定と装飾の分離、矢印操作、無効候補、name/FormData/reset、readOnly、controlled更新拒否、2/4/7候補、複数配置と識別子衝突を確認。

コンボボックスは16素材、入力のfocus維持、hoverと選択の分離、確定/取消、IME合成イベント、入力DOM・キャレット保持、単一/複数選択、グループ、読込/エラー/空、チップの削除、FormData、長いリストのスクロールと背景面の位置を確認。候補のパネルは選択済みチップも含むフィールドの下へ置かれるように修正しました。

通知は16素材、実際のlive本文、閉じる操作と退出中のinert/aria、hover/focusと残り時間、action一回、duration=0、最大件数、API pause/resume、破棄後の処理解除を確認。入口の装飾は変形しますが、本文やボタンのクリック位置は移動させません。

ツールチップは16素材、tooltip/dialogの切り替え、hoverで領域をまたぐ操作、Escape、focus復帰、内容変更と内部の入力保持、実dialog上のtop layerを確認。

全64種類について、小さい画面、縮小モーション、停止後・破棄後のRAF数、popup残留を確認。強制配色では装飾がなくても操作・選択状態が残ることを確認しました。

## 環境と確認できなかったこと

Linux / Node.js 22.16.0 / TypeScript 5.8.3 / 実Chromiumを使用しました。ブラウザー用のドライバーは環境に存在するPlaywright 1.57.0-beta-1764944708000です。プロジェクト指定の1.63.0を取得して実行したという意味ではありません。

npmレジストリは名前解決できず、Vite・React・公式型定義一式を取得できませんでした。**実Vite build/HTTP、今回変更したReact版の実行、React/ツール全体の型チェック、npm audit、GitHub Actionsの完走は未確認**です。

`typecheck:react` はReactと型定義不足、`typecheck:tools` はNode型定義不足で実際に失敗しています。出力を `resonance-checks/typecheck-*-unavailable.log` に収録しています。仮の型定義や独自Reactを使って成功したように扱っていません。

ブラウザーテストは明示的に `SOP_TEST_MODE=offline` を指定し、同じソースからコンパイルしたJSとCSSを本物のChromiumへ読み込みました。ギャラリーも実際のカタログとアプリ実装ですが、配信経路だけがテスト用です。ブラウザーのポリシーは変更していません。agent-browser CLIは未インストールのため、利用可能なPlaywrightで確認しています。

React向けのファイルは実装・ソース依存解析・TSX→JSXの変換・配布内容の照合までです。変換はReactの実行や型チェックの代用ではありません。

Windows実機、iOS/Safari/Firefox、実際のIME、実際のスクリーンリーダーでの読み上げは未確認です。視覚確認・合成IMEイベント・DOM/ARIA属性の確認と区別しています。
