## 環境と未確認事項

Linux、Node22.16.0、TypeScript5.8.3、Chromium144.0.7559.96、環境に既存のPlaywright1.57.0-beta、Node型24.0.4を使用しています。Reactはインストール済みPlaywrightのtrace viewer用ESMに含まれる本物のReact19.1.1/ReactDOM productionランタイムです。versionとcreateRootを確認し、テスト時にのみ使用しました。このランタイムやローカルnode_modulesのリンクはZIPに含めません。依存指定をテスト環境のバージョンへ変更したものではありません。

npmレジストリを名前解決できないため、**指定したViteによるビルド・HTTP配信、プロジェクト固定の公式React/Vite/Node型を含むtypecheck全体、npm auditは未実行です。** ツール側のtscはViteモジュール/型が不足して終了したため、成功とは報告しません。

ブラウザー確認は同じ実ソースを合成テスト文書・ネイティブESM/Blobで読み込む明示的なオフライン方式です。HTTP配信の確認として扱いません。通常の環境では各テストがViteを起動します。agent-browser CLIは環境に存在しなかったため、Playwrightで実行しました。

Reactの開発版StrictMode固有の二重Effectは未検証です。productionランタイムでの明示的なmount/unmount反復とは区別しています。**Windows/iOSの実際の日本語IME、OSの入力補完/パスワードマネージャー、Safari/iOS実機、Windows Explorerのブロック判定、GitHub Actionsの本番実行は未確認です。** 合成IMEが通ったことを実IMEの完全な保証とはしません。

Clipboardの成功/拒否はテスト用のwriteTextで確認し、OSクリップボードを操作したものではありません。保存ファイルとパーツZIPの内容は、ブラウザーの実downloadイベントで取得して照合しています。

## 再実行

```powershell
npm install
npx playwright install chromium
npm run verify
```

テキストボックスだけを検証する場合は`npm run test:textfields`。全144部品のマトリクスを省略せず実行するため、CIの時間上限は40分へ拡張しました。テストの削除や型チェックの無効化は行っていません。

機械可読結果はverification.jsonです。全体ZIPは生成直後に再読込し、CRC・全ファイルのSHA-256を照合します。これらは転送整合性の確認であり、ウイルス検査やWindowsで無警告になる保証ではありません。
