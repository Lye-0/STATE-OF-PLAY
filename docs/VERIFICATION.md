React19の開発版StrictMode固有の二重Effect、Windows Explorerのブロック判定、Safari/iOS実機は未検証です。明示的なmount/unmount反復と実機OS検証を区別します。

## 再実行

```powershell
npm install
npx playwright install chromium
npm run verify
```

通常環境では実Vite・インストールしたReact19・公式型定義を使う構成です。オフライン用環境変数や検証時の依存リンクは不要です。
今回の依存バージョンはv3.3.1から変えていません。新しい検証は`npm run test:disclosures`で個別実行できます。

機械可読版はverification.jsonです。全体ZIPは再読込しCRC/SHA-256を確認します。これらは転送整合性の検証であり、ウイルス検査やWindowsで無警告になる保証ではありません。
