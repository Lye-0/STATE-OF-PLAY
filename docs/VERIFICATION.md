# v3.6.0 検証記録

検証日: 2026-09-22。基準はv3.5.0の全体ZIP。GitHubへのコミット・pushは行っていません。

## 対象と変更

ボタン24種類（A16/B8）とリンク16種類（A10/B6）を追加し、8カテゴリ184パーツになりました。
既存144パーツの本体フォルダー内1,440ファイルは前版とバイト単位で一致しています。
Vite＋TypeScript、4形式、2配置、コード表示、コピー、パーツZIP、AI用プロンプトを維持しました。

操作はネイティブbutton、移動はhref付きaに分離。デモの待ち時間・カウンター・リンク先はアプリ内だけで使い、配布パーツへ混入させていません。

## 環境と未確認事項

Linux、Node22.16.0、TypeScript5.8.3、実Chromium、環境にあるPlaywright1.57.0-betaを使用。
Reactはインストール済みPlaywrightのtrace viewer用ESMに含まれる本物のReact19.1.1/ReactDOM productionランタイムです。
Reactの代替実装やダミーは使用していません。テスト専用ランタイム、ローカルnode_modulesのシンボリックリンクはZIPに含めません。
依存の指定は前版から変更していません。

**npmの名前解決に失敗する環境のため、指定Viteによるビルド・HTTP配信、固定した公式React/Vite型を含むtypecheck全体、npm auditは未実行です。**
ツール側のtscは、Viteモジュール/型が不足するエラーで終了しました。型チェックを無効化したり代替型を作って成功扱いにしていません。

ブラウザー確認は実ソースを合成テスト文書・ネイティブESM/Blobに読み込む明示的なオフライン方式です。
Vite/HTTP配信の成功とは区別します。通常の環境ではテストがViteを起動する既定動作です。
agent-browser CLIは環境に存在しなかったため、Playwrightで実行しました。

Reactの開発版StrictMode固有の二重Effectは未検証です。productionランタイムでの明示的なmount/unmount反復とは区別します。
Windows/macOSの実際の修飾キー・右クリックメニュー、実スクリーンリーダー、Safari/iOS実機、Windows Explorerのブロック判定、GitHub Actions本番実行は未確認です。
修飾キーのイベント検証と、OSのタブ/ウィンドウ管理の実機検証を同一には扱いません。

Clipboard成功/拒否はテスト用writeTextで確認し、OSのクリップボードへ書いたものではありません。
保存ファイルとパーツZIPは、ブラウザーの実downloadイベントで取得して内容を照合しました。
CRC/SHA-256は転送・格納の整合性検証であり、ウイルス検査やWindowsで無警告になる保証ではありません。

```powershell
npx playwright install chromium
npm run verify
```
