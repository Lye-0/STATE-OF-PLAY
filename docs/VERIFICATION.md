# v3.7.0 検証記録

検証日: 2026-09-22。基準は前回提供したv3.6.0の全体ZIPです。GitHubは変更していません。

## 対象

タブ24種類・セグメント24種類（各A16/B8）を追加し、10カテゴリ・232種類になりました。
既存184パーツの本体1,840ファイルは前版とバイト単位で一致しています。

タブはtablist/tab/tabpanel、セグメントは実radioを使用。展示の3項目を本体の制約にせず、items/DOMの増減・並べ替えに追従します。
タブの本文はhiddenで隠して状態を保持し、セグメントはネイティブフォームへ接続します。
選択マーカーはイベントとサイズ変化で実際の座標を計測します。常時RAFやCanvasを追加していません。

## 環境と未確認事項

Linux、Node22.16.0、TypeScript5.8.3、実Chromium144.0.7559.96、環境内のPlaywright1.57.0-betaを使用。
ReactはPlaywrightのインストール済みブラウザーバンドルに含まれる本物のReact19.1.1/ReactDOM productionです。
Reactをダミーで代替していません。開発版StrictMode固有の二重Effectは、この実行では検証していません。
明示的なmount/unmount反復・クリーンアップは確認しています。

**npm pingはレジストリのDNS解決でEAI_AGAINとなったため、指定Viteでのビルド・HTTP配信、指定依存一式のインストール、npm audit、公式React/Vite型を揃えたtypecheck全体は未実施です。**
ツールのtscを実行した結果、Viteモジュール/型が見つからない10件のエラーで停止しました。欠けた依存を仮の型で置換して成功扱いにはしていません。
ブラウザー確認は実ソースを合成テスト文書とnative ESM/Blobで実行する明示的なオフライン方式で、Vite/HTTPの成功とは区別します。
通常のテストは実Viteを起動する構成のままです。agent-browser CLIが環境に存在しないためPlaywrightで確認しました。

Windowsの実機、iOS/Safari、実スクリーンリーダー、OSのIMEやブラウザーUI、Windows Explorerのブロック判定、GitHub Actionsでの実行は未確認です。
Clipboardの成功/拒否はテスト用writeTextで検査します。ユーザーのOSクリップボードを書き換えたものではありません。
ファイル保存・パーツZIPはブラウザーのdownloadイベントから取得した実ファイルを比較しています。
CRC/SHA-256は格納・転送の整合性検査であり、マルウェア検査やWindowsで無警告になる保証ではありません。

## 再実行

```powershell
npm install
npx playwright install chromium
npm run verify
```

新カテゴリのみは`npm run test:selection`。全体のverifyには既存カテゴリの専用テストも含みます。
今回は既存カテゴリの専用ブラウザースイートを個別には再実行せず、全体回帰と単体テストで確認しています。
