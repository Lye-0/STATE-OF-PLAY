# 通知Aタイプの再設計 — v4.13.3

通知が「選択できる素材カード」に見えないよう、知らせの到着、短い表示、退出という役割を造形の出発点にしました。ラジオ／選択カードやコンボボックスと共用していた描画を通知から外し、16種類の短い出現動作と、伝票・信号・注記などの通知専用の構図を用意しています。Bタイプ8種類は変更していません。

| Aタイプ | 通知の構図 |
|---|---|
| Aurora | 上縁を通る光の帯と窓状の面 |
| Mercury | 横から届く金属の伝票とレール |
| Obsidian | 縦の裂け目と内側の光 |
| Prism | 分光する端片と斜めの境界 |
| Folio | 折った紙、左の余白と罫線 |
| Blueprint | 開いた製図枠と注記の位置 |
| Botanical | 余白に置いた押し葉 |
| Copper | 鋲で留めた掲示板 |
| Nixie | 下縁の電極が灯る表示 |
| Ceramic | 磁器の小さな印 |
| Velvet | 上縁の布のひだ |
| Tide | 下縁から上がる水位線 |
| Aperture | 文面の外側で開く絞り |
| Transit | ミシン目のある案内帯 |
| Contour | 左端の等高線 |
| Relay | 順に伝わる接点 |

`notify({ title, description, tone, duration, actionLabel, onAction })`の実データが通知の本文です。装飾は`aria-hidden`かつ操作を受け取らず、表示用の文字を複製しません。`duration`は表示の残り時間であり処理の進捗ではありません。hover・focus・非表示タブ・一時停止中は残り時間を保持します。閉じた通知は退出中も読み上げ・操作対象から除外し、取り外し時にはタイマーとアニメーションを解除します。

各パーツの配布CSSは`resonance/notice-style.css`を、ReactとVanillaの配布コードは`resonance/notice-art.ts`と実際のコントローラーを含みます。静止見本にも同じ装飾を使い、ギャラリーだけの演出にはしていません。動きを減らす設定と強制配色では装飾を抑え、内容と閉じる操作を優先します。
