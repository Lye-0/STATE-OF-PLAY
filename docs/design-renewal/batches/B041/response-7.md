# B041 独立検査への対応

6点を実構造から再設計。索引は連続後帯の負の窓、図面は一体の幅広い経路、凹記録は全高の曲壁、活版は実日時と本文の大きい非対称組版。折り手順と石道は現在の実章から入力床へ接続。

多手順の短い名称の折返し、Enter・controlled拒否・親の受理・非同期errorでのフォーカスを補正。native DOMを接続したまま更新し、実typing undoを保全。25件の永続HTTP回帰検査へ実フォーカス・caret・Undo・破棄後resetを保存。

独立検査5で見つかった長いエラーの入力遮蔽は、別の自然高の行へ修正。6で見つかった長い実章名の固定累積位置ずれは、実grid行の自然高へ変更。索引小口も実下層の切口を4pxずらす方式で描画。

固定スナップショットの展示補助CSSがnative sectionへ当たる問題も発見。元の0は保持し、補助CSSをsection[data-part]へ限定した中立版で修正前画像を撮り直した。対象の元component sourceは変更していない。
