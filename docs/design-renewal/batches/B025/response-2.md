# B025 round2への対応

R354は角丸の四辺枠/上中央の切れ目/二脚を全撤去。CSS gridで実dropzoneと実filesの二行へ同じ連続平底を通し、手前64pxの浅い曲面と10pxの接地面を持つ一つの器にした。空状態は投入面がその器の底、追加後はファイルとnative削除が同じ底へ乗り、件数に応じて全体が伸びる。読面を曲面から82px離し、前縁へ文字を載せない。装飾のためのwrapper/API変更はない。

自検1のアップロード狭幅検査は.art内flexで後置したformのauto幅が36pxへ縮んだfixture問題。form width100%/minWidth0を設定して実長文narrowを再確認。Reactのcontrolled resetはnative reset直後とcreateCoreのsetTimeout復元の間で観測したため、復元をwaitForFunctionで待って親値との一致を確認した。いずれも本体の挙動を弱める変更なし。

選択行の狭幅可読性：全7uploadsでstrongの継承nowrap/ellipsisを廃止し全文折返しへ。container240px以下はpreviewを省き、名前と補足を全幅の上段へ置き、native削除を下段右へ分離する。R355の前壁とR357の支持を維持しながら、短いsingle.txtも判別できる全幅を確保する。
