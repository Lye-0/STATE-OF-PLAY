# B029 独立4対応

R399読む面を一枚紙へ、paper始端26/支持幅34で端8重ね。曲げ材はlogical border+scaleXの二重反転を廃止し、同一SVGをwhole一度鏡映。R404胴縁10/板端6で両端4接触。R403閉じ額の全高左右壁/対称台形を廃し、offset24の中央紙面/互いに反対の上下の返し/開いた側端を持つZ折へ。R412長い祖先文字のRTL線路侵入は物理paddingを全行logical38/12へ揃えて修正。

R401実数字拡大だけではA不足を認め、赤罫を廃止。L断面の側受け28/下底14/共有の込め物床へ、実現在の大きな活字面と14/8/12の三面を接続。他の小さい実索引は同じ床に固定する。

総数1など実表示が少ない場合に空の枠を作らないよう、布/硬貨/シャトル/折紙/書票は最低高を固定値から実行数に合わせた自然高へ変更。通常7slotの外形は保持。

主担当少数検査でR399の総数1に高さ48差を固定すると両支持の高さが消えることを発見。支持差をmin(48px,25%)へ制限。12pxの実曲材の厚さは伸縮画像で薄くせず、物理left/border-blockで描き全体一度鏡映する。通常7slotは48差を維持する。

独立6のR403指摘で、中央面の背景が上下返しの外側を塞ぐことを修正。背景をy44〜H−44の読む紙だけに限定し、返し外側の三角は実背景を通す。

独立7でRTL background shorthandの詳細度がsizeを戻す不整合を確認。LTRと同じ読む紙範囲をRTL詳細度のselectorへ明示する。
