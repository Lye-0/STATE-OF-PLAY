# B023 round2への対応

R317の内三角の上頂点はx12に対しy=18.75%H+18pxへ変更。外斜辺y=18.75%Hから常に18px内側となり、通常/長文の高さに追随して余分な外楔を作らない。

R319の三本の色帯は廃止。一つの全幅110px高の中空陶製アーチ/18px上曲面/16pxの両脚と、88pxから始まる説明板へ変更。両脚が読む板へ6px/22px高で接続、空いた穴が実際の下層へ透過する。読みとnative操作は板へ固定。

R324の厚い額縁は全廃。見出し梁/枠で囲まない本文/二つの開いた鋳造溝/実操作面へ分ける。仕様値を14/20pxの上下肉厚と12pxの奥壁を持つ独立した開端溝に印字。読む文字は溝の内面へ固定し、片端の開口と陰影で面の深さを表す。表示幅は340px（画面幅−24まで）として長文/native入力を確保。
