# B022 round2への対応

R312のヒンジはスクロールする見出しの擬似要素から、表示枠の蓋へ移す。三つの36×10pxの実ヒンジが読面に12px重なって接続し、本文/操作スクロールから独立する。任意のnative入力も読面へ収まる最大幅を指定。

R314の交互三面/全幅折返しを廃止。一枚の読む板へ、見出し36px/品質28px/設定24pxの三つの索引片を接続。値は一枚の読面、実項目名は対応する索引片に表示。本文とnativeチェック/適用は同じ板に固定。R222の交互三面支持を反復しない。RTLでは文字を反転させないことを確認する。

共有標準hintのフォーカス移動では元snapshot0も新1もcheckbox実クリックで失敗。移動先relatedTargetが同部品なら閉じず、nullのときだけ0ms後に確認。timerはdestroyで破棄。resonance系は別runtimeのため変更対象外、回帰テストは標準runtimeを使うessential-popoverへ指定。
