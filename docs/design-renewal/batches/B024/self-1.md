# B024 self1への対応

書背の14px/溝の止壁12pxが最初の小進捗を覆わないよう、壁の先から読む充填領域を開始し、割合は実内側の幅へ適用。native probeの割合はparentの実content幅（clientWidthからpaddingを引く）と比較し、0/1/25/50/72/99/100を検証する。内側の100%は領域の端へ到達する。

二軌道の点は外楕円と独立した円を回さず、実SVG circleの半径51/120=42.5%へ正確に接続。124/110pxの大きさへ追随し、到達角はnative割合に一致。外楕円は固定した装飾基準、到達点は内環の実終端という説明へ統一。

indeterminateでは、直前の値を幅として維持せず、動き軽減時は40%の中立な部分面を表示する。native valueを除き、数値は…へ切り替える。強制色では素材の壁を消すので内側の余白も0へ戻し、native幅と表示の全幅を一致させる。
