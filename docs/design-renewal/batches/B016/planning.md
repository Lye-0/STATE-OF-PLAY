# B016 元監査と計画

対象はR220–R226、R228、R230、R232。K/Liquid Glassは対象外。R220は左一本線だけの本、R222は薄い本文欄だけで図面の構造なし、R223はピンクの通常矩形だけ、R224は磁器/盆を説明する通常フォームで名前もLetterpressとの不整合。これらRは配置・外輪郭・支持を作り直す。R221は上帯/大字/丸主操作の個別の輪郭を揃え、R225は区分線を残して二重枠を減らす。B R226/228/230は実用の構成を保ち本文の重さ・暖寒の不整合を直す。R232は橋のつまみを残し多数の平行線を主/補助軌道へ整理する。

本は左右の頁の内容と綴じ目へ、図面は全幅の布ポケット、台は12pxの実空隙を持つ二つのプラットフォーム、盆は実際に抜ける40×120px持ち手へ変更。名称Open Spread/Porcelain Handleへ表示名のみを変更し安定ID/APIを保持。native本文・操作・フォーカスを固定し、任意本文と長い表の局所スクロールも確認。原版snapshot0からnativeを実際に開いてbefore画像を取得。試作1自己検査後、ポケット口の端で3px接点不足を見つけ前壁35pxへ修正、全端で紙の下端へ重なるようにする。
