# Table implementation

## archive-ledger-table

一枚の実台帳を40pxの製本断面へ接合し、実件数を見出しから抜き差しする幅104pxの索引片へ編集する。件数の紙が24pxの下小口と異なる高さで開き、全行は同じ連続した記録面に保つ。四辺の色枠や行カードは作らず、実索引と表本文の接合が主形になる。

## inspection-grid-table

上の実検索治具と下の実ページ送り治具が、開いた左右の厚い爪で一枚の検査表を挟む。飾り目盛りと行カードを作らず、列の読みと実操作を厚い顎の接合から分ける。上爪は32px本文へ入り、下爪は独立した現在ページを支える。

## folded-register-table

実検索と選択の操作帯が左の32pxの折面から入り、下の32pxの折り込みで一枚の実台帳へ接合する。本文の下は実ページ送りの右返端だけが開く。表のセルや文字を折らず、操作帯・本文・現在ページの実領域が異なる向きの折面を持つ。

## stone-record-table

一枚の実記録を左上72px・右下64pxの非対称な石の面へ刻み、表本文は上下16pxの広い溝に沈める。実件数だけが上の段から32pxの湾曲した肩へ降りる。各行を石片にせず、直線的な列と大きい石の外形・実件数の二段の面で見分ける。

## letterpress-data-table

既存の活版題字と一枚の薄い紙面を残し、実件数を幅104pxの独立した欄へ編集する。四つの競合する罫を削り、題字・列見出し・ページ送りに同じ4pxの組版の基準を揃える。大見出しだけで主張せず、実件数と表の情報編集を一つの比率へ整える。

## index-drawer-table

既存の引出しの上蓋・本文・前板の段差を保持し、重い茶色を上蓋と前板の16pxの小口へ限定する。実表は左右16pxの内側へ入り、通常・選択・操作を不透明な一枚の明るい紙面へ揃える。検索の重ね枠と行ごとの厚い段差は削り、実記録が主役の引出しに整える。

## rail-dataset-table

実表の右の40pxの可視レールが上の実見出しを受け、下の現在ページは反対の左レールへ片寄って支えられる。一本の通し線に行カードを貼らず、一枚の実表を二つの異なる片持ち位置へ留める。実行・選択のセルは連続した記録面に保つ。

## stitched-register-table

実台帳を左の幅16pxの布の耳にまとめ、外の幅24pxの大きい交差糸へ接合する。細い縫い線で四角い枠を飾る方法を廃し、開いた左の耳と糸の可視接合を主形にする。実表は布の一枚の本文に固定し、行と文字へ縫い目を反復しない。

## open-sheet-table

既存の開いた一枚の紙と余白の編集を保持し、題字を30px、狭幅24pxへ抑えて列名との比率を整える。実件数を題字の下端へ揃え、検索と実表の間隔を同じ28pxへ統一。薄い紙の通常面と2pxの列見出しだけで、飾り枠を増やさず読み順を磨く。

## receipt-index-navigation

一枚の実行先の右を幅80pxの実現在地の控えへ分け、切取り線はこの実控えとの境界だけに置く。現在地の実名称は縦方向に読み、長い上下のレシート枠や各行の偽票を廃す。実モバイルでは現在地の控えが下の切取り帯へ回り、方向に応じた読み順とnative操作を保持する。


# Formal1 response / round2

## archive-ledger-table

外周の背と件数小札を廃し、一枚の連続記録が現在ページの前端の実開口へ入る索引原紙に再構成する。実ページ範囲は112pxの広い前端面、件数は原紙の上の読む端へ編集し、下の一つの切断面だけがページ送りの厚みを示す。空・検索・1ページでも架空の票を増やさず本物の範囲を読む。

## inspection-grid-table

検索帯の対向顎を廃し、実列見出しとnative列幅操作を一つの深い計測横桁へ集める。実列名が上の読む面、28pxのresizerが列境界の側面、24pxの下小口に実幅pxが表示される。数値はaria-valuenowから読み実幅に追従し、幅操作なしの列には偽工具を置かない。

## folded-register-table

外周の小折角を廃し、実検索と選択操作の背面から本文の前面へ一回だけ内側で返る長い紙に再構成する。48pxの真空隙を残し、右の大きい返面が操作背面から表の入口へ届く。native列と文字は前紙の水平面に固定し、実ページ送りは同じ前紙の下の自由端へ置く。

## stone-record-table

対角の丸角板を廃し、実件数を含む大きい斜めの肩から、実検索で抽出する表の開いた床へ片側だけ96pxの割れを降ろす。一体の石の読む床は不透明に固定し、左は深い割れ、下は24pxの連続切口で異なる断面を示す。実行を石片へ分割せず、空とエラーも同じ床で読む。

## rail-dataset-table

対角L枠を廃し、実識別列と選択列の固定床から、残りの列が横へ滑る一つのクロススライドへ再構成する。固定する識別列の24pxの側面が動く記録の境界を担い、下のnative横スクロールが実端点と位置を示す。飾りのつまみや偽目盛りは作らず、列幅とRTLの移動をnative表へ一致させる。

## stitched-register-table

左綴じと交差線の反復を廃し、実列幅を持つ布帯の見出しが一つの56pxの共通縫い代を通り、本文へ降りる織り登録面に再構成する。孔と糸は実column境界へ置き、列幅調整に追従する。表の四辺へ縫い目を描かず、情報の列と布の方向を一致させる。

## letterpress-data-table

承認された通常の主形を保持し、選択の読む領域の同寸予約とforced colorsの実glyph/backplateのみを修正。

## index-drawer-table

承認された通常の主形を保持し、選択の読む領域の同寸予約とforced colorsの実glyph/backplateのみを修正。

## open-sheet-table

元の軽いセリフ、下罫だけの検索、囲まない状態表示へ戻し、選択幾何とforced文字だけを追加修正。


## receipt-index-navigation round3

実行先群を一枚の幅広い紙へまとめ、その終端が48pxの開いた内側の返しを通って実現在地の読む面になる。細い縦書き控えを廃し、160pxの横書きの局所スクロールで全文を読む。実dialogでも一覧の終端が同じ実現在地へ返り、unknownでは偽の値を置かずnative行は固定する。

固定2はdefaults同期のscript例外による未完成self snapshotとして棄却しました。固定3でmarkup/Vanilla/Reactの既定を一致させています。


# Formal3 response / round4

## archive-ledger-table

実ページそのものを選ぶ大きい索引を一枚の実記録の端に置く。索引は実page数と現在pageから作り、ネイティブボタンの番号で読む原紙を切り替える。件数小札や装飾の背を廃し、112pxの実ページの自由端と連続した表が一つの資料になる。多ページは前後2と両端に限定し、架空の紙束は増やさない。

## folded-register-table

実検索と選択を載せる220pxの背面を実表の隣へ置き、全高の48pxの一枚の返面が記録前面へ回り込む。二面を細い取手でつながず、操作面の向きと本文の向きを一つの長い折面で決める。狭幅では同じ広い返面が上へ回り、native検索・文字・押面を変形しない。

## stone-record-table

灰白の露頭の全高を大きい傾斜と長い割れで一体に切り出し、その内側に水平な実記録の床を収める。件数・検索・現在ページは同じ露頭の上面へ置き、実表だけが深い16pxの切口を持つ読む床になる。短い隅欠けや丸角板を廃し、長い非対称な断面の外形と実記録の平面を対比する。

## rail-dataset-table

実記録が滑る床と、native横移動へ双方向に接続する大きいクロススライドを一体にする。72pxのnativeつまみと厚い受け溝は飾りではなく、実表の先頭・末尾を直接読む操作を担う。識別列の固定床は幅に余裕があるとき保持し、狭幅では選択列だけ固定して他の実列を読めるようにする。

Inspectionは設定幅の明示と旧pseudo insetの全解除、Stitchedはnative sticky見出しの原点保持、全9表の数値はLTR isolateへ限定しました。共通UIの選択予約/forced glyph色は保持しています。


# Round5 preflight

ReceiptのCSS末尾に残った旧64pxの側橋指定を削除。全幅64pxの返曲面を実computedに一致させる。Archive実索引の紙端との8px隙を除き、実ページの読字面には紙と同色の不透明背景を置く。native端・文字・状態の寸法を変えない。


# Round6 Rail

実識別列と選択列の固定床が、その実幅のまま下へ続いて横送りの溝を支持する。実表の24pxの小口から、開いた横送り溝と80pxのnative鞍形つまみが交差して出る。独立した塗り矩形のrangeパネルを廃し、固定床・支持小口・可動読面の前後を一つの断面にする。実横scrollと双方向に同期し、狭幅で固定識別列を解放すると支持も48pxへ戻る。文字は不透明な水平面で読む。
