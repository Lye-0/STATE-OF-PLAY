# Implementation

## folio-register-table

題字と実件数を一つの紙葉の上のタブに編集し、本文の一枚の紙を32px斜め下へ差し込む。上のタブの丸い返端と下の尖った小口が異なる開き方を持ち、表本文と列名は平らな一枚に保持する。各行をフォルダ化せず、実資料の題字と本文の差し込みが主形になる。

## caption-register-table

実見出し・実説明・実件数を表の横に独立した一つのキャプションとして編集する。件数はキャプションの最下段で本文の末尾に対応し、表の検索と列の読みは横の一枚の記録へまとめる。狭幅ではキャプションが表の上へ回り、本文は32px内側に入り、別の読む面であることを保つ。

## blueprint-register-table

上の実題字と件数が一つの設計票となり、表の検索・列・現在ページは48pxずれた実記録面へ降りる。上は垂直の断面、下は40pxの長い斜めの断面で、実件数の縦の読む位置と本文の水平の列を異なる接点へまとめる。架空の目盛りやねじを増やさず、実票と本文の断面を主形にする。

## ribbon-register-table

実検索と選択解除だけを一つの幅広い帯へまとめ、題字から左へ抜き出して、24px下の返端を表本文へ差し込む。帯は一つだけで、列や各行を紫の帯に反復しない。実操作を含む前の帯、返端、白い本文の三つの接合で前後を見せ、文字と操作面は常に水平に保持する。

## ceramic-register-table

実件数の小さい陶の肩から、実検索を受ける大きい開いた陶の取手へ降りる。取手の中は背景が見える空隙で、下端だけが表の読み口に接する。本文全体を丸い容器にせず、曲面と厚みは件数・検索・本文の入口に集め、実列と記録の面は直線に保つ。

## receipt-register-table

実件数を題字の左の短い控えへ分け、表の末尾から実現在ページの控えを48px離して右へ抜き出す。上の縦の切取境界と下の実ページへ届く細い紙橋が異なる分離を示す。表の各行へレシート模様を反復せず、全件数と現在ページの二つの実控えだけが切取の形を持つ。


## rotary-gate-loader

六つの開いた同心ゲートという元の主形を保ち、2.5pxの輪郭と10pxの間隔へ整える。交互の明暗を抑えた灰青で前後を読み取り、ゲートの位相差は連続した3.2秒の往復に揃える。

## spooling-ovals-ornament

一本の実芯と六つの巻く楕円を保持し、芯18px・輪2px・25px間隔へ読みやすく磨く。密な極細線と下影を廃し、輪の傾きだけに位相差を持たせ、芯と巻きの接点を静止時にも明確にする。

## telescopic-stroke-loader

六段の伸縮筒という元の主形を保持し、水平だけに伸縮する異なる長さの層へ整える。最小層を細い点にせず、段ごとの左の厚みと伸び差で一つの軸を示す。元の全体が上下に漂う動きは廃し、入れ子の面と実際の伸縮の方向を一致させる。

## lift-platform-loader

六つの昇降床の元の波を保持し、各床を実際の伸縮支柱で一つの基床へ接続する。床を上下させる高さと支柱の長さを同じCSS変数で駆動し、上下動のどの瞬間にも基床へ届く。小箱の波だけに見えない接続と、灰青の平たい床の厚みを磨く。


# Main preflight after round1

表の選択領域を同寸予約し、forced選択の実glyph/backplateへsystem色を適用しました。native viewportの100%幅にmarginを足していた4件を実幅からmargin分を引く指定へ修正し、狭幅は表内だけスクロールします。Captionの実見出し床は透明な暗背景上では読みにくいため、不透明な紙面へ固定しました。機構4件は固定1と4で作者ファイル不変（native動作/3時点描画範囲/停止/縮小動作/強制配色は固定1の実証を継承）。


# Round7

# Independent round6 response

## folio-register-table

丸タブと外紙を廃し、actual列名・sort・resizeを一枚の連続した64pxの折り冠へ編集する。実columnの境界で山谷が交互に接し、平らな読む前面が同じ本文列へ降りる。偽の紙葉や金属combを置かず、actual columnsだけが紙の折面を決める。文字・値・native押面は水平のまま保持する。

## caption-register-table

実題字の上面、実説明の前面、実件数の足面が一つの三角断面で連続する自立captionへ再設計する。側captionを表の全高へ伸ばさず実内容量で高さを決め、64pxの側断面と40pxの足が自立する関係を示す。狭幅は全幅で題字・説明・件数を縦に読み、62pxの細い題字へ戻さない。

## blueprint-register-table

上下のずれた板を廃し、実column名の上軸と、sort/filter/page後のactual表示位置を読む80pxの片側軸を持つ開いた照合原図へ再設計する。行番号は実page・pageSize・可視順から導き、架空の目盛りやIDを置かない。24pxの上軸と16pxの側断面の交点だけに厚みを集め、下と反対側は開放する。

## ribbon-register-table

実queryの裏面と実選択数・解除の表面を、一回の大きい半ひねりで連続する布へ再設計する。88pxの平らな二つの操作面が112pxの高さ差と48pxの空隙を渡り、全幅の二つの斜めの縁が表裏の向きを変える。短い返端・割尾・孔を廃し、非選択でも選択面の寸法を予約して文字と押面を動かさない。

## ceramic-register-table

丸角板と外U取手を廃し、actual row action列を受ける全高の深い陶の側溝と広い平底へ再設計する。40pxの外口縁・16pxの内縁・上80pxと下72pxの一続きの曲面が、実action押面を包んで読む底へ戻る。行ごとの小皿に分割せず、actions無しなら溝も存在しない。溝を含めたactual tableだけが局所scrollする。

## receipt-register-table

件数小控えと離れたfooter票を廃し、actual checkbox列そのものを80pxの全高の確認控え帯へ再設計する。選択数・解除が上端、実行ごとの確認欄と交互の大きい紙肩が本紙との分節を決める。未選択でも帯を予約し、本文・glyph・native押面を動かさない。選択不可やcheckbox無しでは架空の確認欄を作らず、ページ送りは同じ本紙の下端に置く。

Motion3のforced限定修正:ゲートの欠けをborder-style noneで保持/楕円内部を透明にして芯を保持/基床をCanvasTextのborderで保持。696の合格主形を維持。


# Round9 UI preflight response
