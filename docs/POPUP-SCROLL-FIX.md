# ポップアップ表示時のスクロールバー修正

## 症状

ポップアップを開くと、表示アニメーションの開始時に右端と下端へスクロールバーが一瞬現れる。動画と共通のネイティブ<dialog>スタイルを確認した。

## 変更

共通CSSではトップレイヤーのダイアログ枠を`overflow:hidden`にして、スクロールバーを枠の外へ出さない。本文シェル`.sop-popup-shell`に高さ上限と`overflow-y:auto; overflow-x:hidden`を設定し、長い内容だけを縦スクロールする。素材を動かすTRANSFORM系のシェルにも同じ契約を適用し、狭い画面高でも最小高さがスクロール領域を押しつぶさないようにした。

React/Vanillaの配布ソースは共有CSSを含むため同時に更新される。全24種類の詳細画面にある使い方とAI用プロンプトにも、外枠は固定し本文だけ縦スクロールする仕様を反映した。

## 確認

ポップアップのブラウザー回帰確認は**11項目成功**。全24種、320/390/504×356/768pxでの枠内配置、横方向のはみ出し、標準・TRANSFORM系の長い本文を縦スクロールできることを確認した。実行はPlaywrightのオフラインモードとローカルMicrosoft Edgeを使用した。Vite開発サーバー経由はこの環境で10秒のページ読込期限を超えたため、回帰確認はオフラインモードで完了している。

TypeScriptのapp/React/tools設定による型チェックは**3件すべて成功**し、Viteの本番ビルドも成功した。配布ZIPは**6,437ファイル**を収録し、CRCとSHA-256の一致を確認した。
