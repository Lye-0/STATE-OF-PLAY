## 実行環境と制約

- Linux、Node.js 22.16.0、TypeScript 5.8.3、実Chromium `/usr/bin/chromium`。
- 実行用Playwrightは環境内にある `1.57.0-beta-1764944708000`。プロジェクトで指定した `1.63.0` を取得したものではありません。
- `agent-browser`コマンドは利用できなかったため、Playwrightから実Chromiumを直接操作しました。
- npmの名前解決ができない環境のため、依存関係の再インストール・実Viteビルド・HTTP配信・`npm audit`・公式React型定義を含む全体の型チェックは未実施です。
- ブラウザーへは元ソースをTypeScriptで変換して読み込む**明示的オフラインテストアダプター**を使用しました。Viteビルドの代用品として配布するものではありません。単一HTMLを成果物へ追加していません。
- React版はラッパーのクラス名と必要CSSの依存を確認し、コントローラー・共有View・フックは変更していません。ただし、今回は実Reactでのmount/更新/unmountを再実行していません。`test:disclosures`のログにもReact未実行を明示しています。
- Windows Explorer、Safari/iOS実機、スクリーンリーダー実機、GitHub Actions上の完走は未確認です。

以上を踏まえ、**`npm run verify`全体が成功したとはしていません**。単体テストの成功、ブラウザー検証の成功、ZIPの整合性、実際の各OS上の動作を区別しています。

## 通常の環境での再実行

```sh
npm install
npx playwright install chromium
npm run verify
```

新しい重点テストだけを実行する場合は `npm run test:sculpture` を使います。通常は実Viteで起動します。オフライン用の環境変数を通常の開発環境に設定する必要はありません。

## リポジトリ全体ZIP

`npm run package` は新しい全体ZIPを作成後、読み直してCRCと全ファイルのSHA-256を照合します。`RELEASE-MANIFEST.json` に収録パス・サイズ・ハッシュを含めます。`.git`、`node_modules`、秘密情報、テスト用ブラウザー文書は収録しません。

チャットへの最終添付前にも別実装（Python zipfile）でCRCとマニフェストを照合し、新しいフォルダーへ再展開してアプリの型チェックと造形回帰テストを確認します。CRCとハッシュは内容の整合性検査であって、OSの無警告やマルウェア判定を保証するものではありません。
