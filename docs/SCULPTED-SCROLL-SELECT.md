# スクロールバー・プルダウンのAタイプ改修（v4.2.0）

## 範囲

Aタイプのスクロールバー16種類、プルダウン16種類だけを改修しました。収録数は25カテゴリ・564種類のままです。
Bタイプ16種類を含む対象外532パーツの5,320ファイルと、既存の共有コントローラー・フックは、v4.1.0とバイト単位で同一です。

「トグル」「ブロック」「テキストボックス」「ボタン」は完成度の参考とし、デザインの単純な流用や名称だけの置換はしていません。各素材の輪郭、厚み、陰影、動き、操作面を作り直しています。

## ソース・持ち出し

新しい共有CSSは `src/shared/scrollbar-sculpted.css` と `src/shared/select-sculpted.css` の2ファイルです。元のベースCSSは変更せず、Aタイプにだけ明示的に読み込みます。
ルートの `sop-scroll-sculpted` / `sop-select-sculpted` クラスはVanillaのmarkupとReactのラッパーの両方に付与します。Bタイプには付けません。別のスキンにも適用される広いセレクターを避けています。

TSX/JSX/TS/JS、導入向け/元の構成の両方で依存CSSも含めて生成します。コード表示・コピー・ZIPは同じ生成データを参照します。独立したパーツへ持ち出してもギャラリー全体のCSSを必要としません。

32パーツのprompt.mdも更新し、古い配色・寸法の仕様は置き換えています。固有CSSを正本と同期するテストを追加しました。パーツのAPIと値は維持し、配置やラベルは利用先の規約に合わせて変更できます。
