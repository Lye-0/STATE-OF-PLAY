## 新しいブラウザー検証の内容

- ページの確定値とaria-currentが先に更新され、装飾の面が後から応答すること。
- 現在ページの実位置・幅から選択面を測定すること。RTL・resize・高速のページ変更に追従すること。
- 先頭・末尾、1ページ、総数変更、10,000ページ以上。数万個のキーを生成しないこと。
- URLモードでhrefを維持し、修飾キーのイベントをキャンセルしないこと。単にcallbackが呼ばれたことを移動成功と扱わないこと。
- 値の外部制御で、更新を受け入れる場合と拒否する場合。
- タグの入力要素を再生成せず、Space・ラベルのクリック・フォームの送信値を保持すること。
- 選択操作と削除ボタンが独立し、外部制御時の削除はitemsの更新を待つこと。
- 削除後のフォーカス、フォームリセット、空の項目、並べ替え、表示／選択／削除モード変更。
- 退出する装飾へinput・button・フォーム名を複製しないこと。
- 任意のアイコンと件数表示、HTML文字列のエスケープ。
- 幅320／390／768px、長い日本語、区切りのない長い英語、長いタグを削除できること。
- 縮小モーション時の描画停止、強制配色時も選択や文字を残すこと。
- ホバー・選択後に自動でフレーム処理が静まり、取り外し時にRAF・Observer・退出演出が終了すること。
- 全604種類のCSSを併用しても、新26種類の主要なcomputed styleが単独時と一致すること。
- 既存Bタイプのページ送り・タグの操作が変わらないこと。

## 実際の環境と未確認範囲

ブラウザーの駆動には環境内のPlaywright1.57.0-beta-1764944708000を使用しました。package.jsonに指定したPlaywright1.63.0をインストールして実行したものではありません。

通常のテストコマンドはViteのHTTPサーバーを使う構成です。今回の実行は明示的な`SOP_TEST_MODE=offline`を使用し、元のコードをコンパイルしたテスト用ドキュメントへ実際のDOM／CSS／JavaScriptを読み込む方式です。ViteそのものやHTTP経路の検証ではありません。agent-browserは環境に存在せず、実際のPlaywright／Chromiumで代わりに確認しました。

npmレジストリへのDNS解決に失敗しました（接続ログ同梱）。そのため**Viteビルド、今回のReact版の実行、指定依存一式の型チェック、npm audit、GitHub Actionsの完走は未確認**です。Reactとtoolsの型チェックは実際に試みましたが、react型定義・node型定義がないため失敗しています。型チェックの無効化やエラー抑制を製品へ入れていません。成功したアプリ型チェックと区別してください。

ブラウザーで確かめたのはイベントとDOM、ネイティブフォーム値、描画状態です。外部ページへ実際に移動してルーターやAPIの成功を確認したものではありません。今回コピー成功時のOSクリップボード実書き込みやユーザーPCの保存先を再検証したものでもありません。Windows／iOS／Safariの実機も未確認です。

## 再実行

```sh
npm install
npx playwright install chromium
npm run typecheck
npm test
npm run test:sequence
npm run test:sequence:gallery
npm run verify
```

`npm run verify`とCIには新しい2つのブラウザースイートを追加しました。通常の利用にオフライン用環境変数は不要です。ロックファイルと独自変更は保持して更新してください。

全体ZIPは `npm run package` で元ソースから生成できます。`node_modules`・`.git`・`.test-output`・秘密ファイル・単一HTMLのプレビューは同梱しません。
