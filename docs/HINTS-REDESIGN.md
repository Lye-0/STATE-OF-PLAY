# ツールチップ／ポップオーバー — v4.13.2

補足情報が「小さな操作の起点から現れる」ことをAタイプの表現軸にしました。ラジオカードやコンボボックスに使った素材面をそのまま拡大せず、情報面の輪郭、余白、開く方向、短い動きを作り分けています。本文・チェック・ボタンは実際のDOMのままです。

| Aurora | 透明な膜が下縁から広がり、見出しと説明を二列で見せる |

| Nixie | 琥珀色の電極が端で灯り、機器の面から情報が現れる |

## 表示と操作

外枠の `ff-hint-panel` は装飾のはみ出しをクリップします。長い本文・操作だけを内側の `ff-hint-content` でスクロールし、展開の瞬間に外枠へ右・下のスクロールバーを出しません。ページや周囲をスクロールすると固定位置のパネルを閉じ、内側のスクロールでは維持します。

`interactive: false` は説明専用の `role="tooltip"` で、hover/focusで開き、トリガーからフォーカスを奪いません。`interactive: true` のときだけ、内部で操作できる非モーダルの `role="dialog"` を使います。Escape、フォーカス復帰、内容更新、複数配置、動きを減らす設定を維持します。装飾は `aria-hidden` と `pointer-events: none` に限定します。

## 実装と配布

Aタイプ14種類のヒント専用の造形と出現は `src/shared/foundation/resonance/hint-style.css` と `hint-art.ts` が担います。ApertureとPrismの既存の幾何学的な場面には `art.ts` を引き続き使います。Bタイプ8種類は落ち着いた外観を維持し、外枠・内側スクロールの修正だけを共有します。

各パーツのコード表示、コピー、使い方、AI用プロンプト、TSX／JSX／TS／JSのパーツZIPに、同じ共通処理とスタイルを含めます。
