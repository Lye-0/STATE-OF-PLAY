## 修正して再確認した点

- 新作のTypography系CSSのtransitionが縮小モーション時に残る問題を修正し、24種すべてでアニメーション停止を再確認しました。
- 従来のテストの「24種」などの定数は、実際のカテゴリ件数から検証する形へ変更しました。過去の24種の保持は別のbaselineテスト、新作24種と全588種は新しい件数テストで確認します。失敗する部品を除外する修正ではありません。
- 新しいレールの有限な残光を考慮し、静止時の待機確認は最長の余韻が収束する時間まで待ちます。破棄時は直ちにRAF・Observer・イベントを解除することを新しいテストで確認しています。
- 開閉を連打したときのinert/aria-hidden、閉じる面の入力遮断、複数配置の識別子、長い候補の内部スクロールを確認しました。

## 再実行

通常の開発環境では次を使います。

```sh
npm install
npx playwright install chromium
npm run verify
```

新作だけのブラウザー確認は `npm run test:kinetic`。通常実行では実Viteサーバーへ接続します。`SOP_TEST_MODE=offline` はネットワーク制約環境用の明示的なテスト経路です。配布用の単一HTMLを作る機能ではありません。
