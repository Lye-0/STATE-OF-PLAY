# WAYFINDER v4.10.1 統合と検証

2026-09-23。受領したv4.9.0→v4.10.0再構築差分を、カテゴリ別遅延読み込みと起動表示を持つローカルv4.9.3へ取り込みました。現行リポジトリは25カテゴリ603パーツ、ローダー39種類です。差分側の604パーツ・40ローダーは、ローカルで削除済みのPaper Loaderを含む元版の数です。

## 取り込んだ内容

- パンくずA10種類・数値入力A13種類の本体、meta、React／Vanilla入口、CSS、使い方、AI用プロンプトを一組で更新しました。
- WAYFINDERの共有描画・操作処理とCSSを追加しました。配布時も同じ正本が含まれます。
- 差分内155ファイルを列挙し、RELEASE-MANIFEST.json以外の154ファイルを全体版マニフェストのサイズ・SHA-256と照合しました。150ファイルを配置し、README・package.json・CI・Atelierテストを現行版に合わせて統合しました。元版のRELEASE-MANIFEST.jsonは採用していません。
- 全素材CSSを混在させる検証で、パンくずと数値入力の同名素材トークンの干渉を発見しました。両共有CSSの素材セレクターを`data-wf-kind`で区切り、単独／混在の計算後スタイルを一致させました。
- 省略パンくずメニューは項目・設定の更新時に閉じ、パネルにフォーカスがあった場合は省略ボタン（なければ残るリンク）へ戻します。23種類の使い方とAI用プロンプトも、今回のCSS境界・操作へ揃えました。
- カテゴリ別の遅延読み込み、Nixie／Orbital Loomの読み込み表示、ローダーの修正とPaper Loaderの削除を保持しました。依存ライブラリの追加はありません。
