# B004 選択位置を保つタブ10件

前回の造形評価は維持し、画面を縮めたときに選択中タブが切れる不整合を修正。原因・実装はB003の共有selection-indicator.tsに集約する。個別CSSへ補正を複製せず、各パーツの使い方に挙動を記載。全10件の元の輪郭・素材・ホバーを再検査する。

- R152 Sawtooth Index Tabs：切歯状の端が索引を区切り、薄い紙面の質感と矛盾しない。
- R153 Hangtag Tabs：吊り札が選択位置を表し、色数と線の量が適切。
- R154 Offset Rail Tabs：レールと紙の境界に一貫性があり、同じ矩形だけの構成から離れている。
- R155 Gabled Tabs：屋根形の索引が輪郭の個性を作り、番号と見出しの階層も読みやすい。
- R156 Copper Pin Tabs：銅のピンがタブと紙をまとめる役目を持ち、装飾の接続が自然。
- R157 Stitched Folio Tabs：背の縫い目が紙面の物理構造と合い、余白の広さを保つ。
- R158 Instrument Tabs：計器の目盛りと独立したキーが選択操作に対応し、軽い色調でまとまる。
- R159 Floating Bookmark Tabs：しおりの切込みを反復し、主題に合う緑で選択位置も示せる。
- R160 Negative Slot Tabs：下側の索引という構造差があり、本文面を広く取れている。
- R161 Slanted Spine Tabs：斜めの背と大きな番号が組み合わさり、固定文字の読みやすさを保つ。

検査：1500→320/390/768、LTR/RTL、末尾選択、キーボードmanual、7項目/長い日本語、縮小されたホスト、reduced/forced。選択やパネル内容を変更せず、ページを動かさない。
