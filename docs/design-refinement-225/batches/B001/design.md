# B001 ホバーの整合性10件

- R024：旧斜めパネルのhover skewを削除。現在の紙面上下罫は固定し、左の蛇腹だけを伸縮させる。
- R030：旧丸角カード用の矩形hover影を削除。抜き型の輪郭と下紙の回転だけで厚みを示す。
- R089：暗い候補面に対するhover/active背景を青灰#314556へ揃え、明るい文字を全状態で保持。
- R146〜R150：矢印で実際に変更するtranslateをtransition対象にし、入口・解除・再進入を連続化。リンク文面・クリック領域は固定。
- R182：先行hoverの暗い文字上書きを削除。未選択は白、選択は淡い面と暗い字。狭幅は等幅gridに変更し、最後だけ倍幅となる折り返しを防ぐ。任意の長いラベルは各セル内で折り返し、縦指定は従来の縦配列。
- R422：暗い展開メニューでhover色が沈む指定を改め、白い文字と下線を使う。位置・展開操作は変更しない。

判定維持505件やLiquid Glassの著者ファイルには変更しない。
