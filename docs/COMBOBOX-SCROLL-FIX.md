# コンボボックス展開時のスクロールバー修正

v4.10.9では、候補を開いた瞬間に右端・下端へスクロールバーが一瞬現れる問題を修正しました。

## 原因

標準の浮動パネルとRESONANCEパネルの両方が外枠を`overflow:auto`にしていました。候補の出現演出や選択面の変形が一時的なオーバーフローとして扱われ、使う必要のない横・縦スクロールバーを表示していました。

## 変更

24種類すべてで、コンボボックスの外枠を`overflow:hidden`にして演出のはみ出しをクリップします。候補が増えて表示上限を超えた場合は、候補一覧の`[data-results]`だけを縦スクロールさせます。横方向にはスクロールしません。表示面の素材・色・開閉アニメーションとフォーム操作は維持しました。

RESONANCEの外枠に独自で設定されていたスクロールバーも、同じく候補一覧の内側へ移しています。候補のHTMLやARIA役割は変更していません。

## 配布コードとプロンプト

24パーツすべての使い方とAI用プロンプトに、外枠は固定し候補一覧だけを縦スクロールする仕様を追記しました。共有CSSと初期化処理は各パーツのTSX / JSX / TS / JS配布へ含まれます。

## 確認

実Microsoft Edgeで全24種類を開き、最初の描画フレーム中も外枠・ページにスクロールバー相当のオーバーフローが出ないことを確認します。長い18件の候補一覧が内部の縦スクロール領域に収まり、キーボードによる選択、Escapeでの閉鎖、全299基盤パーツのマウントと破棄が保たれることを確認します。
