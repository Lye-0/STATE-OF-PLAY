# 判断根拠と、似ていても残したもの

ソースの比較だけで削除対象を決めず、実際のギャラリーで通常表示817件、候補や展開型カテゴリの操作後281件を撮影しました。操作内容は `states.json`、各パーツのソース位置は `inventory.json` の `base` に記録しています。

## 共通実装が実表示に出ている例

- ローダー：`src/shared/foundation/base.css` が旧系列の形と動きを定義しています。Aurora / Velvet / Essentialは三重円の回転（3.6 / 2.3 / 1.6秒）と中心の脈動（2秒）が共通です。Folio / Tide / Outlineも同じ振り子の系列です。G01〜G07は、このように見た目と動きの双方が重なる組です。配色・背景を同じ系列の展開として維持する前提の提案です。
- 紙の選択UI：`src/shared/transit-selection.css` のpaper / mapと、detent / shutterの共通演出がAtlas / Folioタブ、Origami / Atlasセグメント、Detent / Studioセグメントの実表示に強く出ています。元の個別CSSが違っていても、選択後の形が近いため候補にしています。
- 基本入力群：`src/shared/foundation/core.ts` に単値・範囲、刻み、複数選択、タグの選択・削除などの設定があります。初期値やサンプル文言の違いを、そのまま独立したデザインの違いとは数えていません。

アニメーション記録には非表示の装飾要素も含まれます。名前・速度の一致だけで判断したわけではなく、写真に現れる形と元CSSを併せて確認しています。静止画ではアニメーションを固定しており、動画としての完全な比較記録は作成していません。

## 残す理由がある例

- Soft / Paper Popover：明色のトリガーは近く見えますが、Softは設定項目・チェック・適用ボタンを持ち、Paperは説明だけのヒントです。展開後の役割が違うため候補から外しました。`src/shared/foundation/feedback.ts` の `renderHint` とinteractive設定で内容が分かれます。
- 日時入力：単日・期間・時刻・日時で、必要な操作と展開パネルが異なります。削除候補は単日型のEssential / Outline / Compactだけです。
- コマンド：Compactは説明を省いた高密度の一覧。AのAperture / Deck / Spectrumも似たリストですが、開口・折り上げ・左右からの展開が別のアニメーションなので残します。Observatory / Constellationは選択の演出と記号表現が異なります。
- コンテキストメニュー：Compactは密度を変えています。Plainはアイコン省略の違いがあり、今回は優先度「中」として、その差を説明しました。
- ローダー：新しい立体・素材のローダーは旧系列と別の形や動きです。似た円や金属色だけを理由に候補へ入れていません。
- スケルトン：Shimmer / Paperは同じ構成・動きですが暗色／明色の適用先が異なるため優先度「中」。Pulseは脈動型で動きが違うため残します。
- 装飾：Hinge Fan / Fan Sparkは扇の形が重なりますが、常時漂う動きとホバーで開く動きの違いがあります。優先度「中」で、ホバー反応を優先してFan Sparkを残す提案です。

## 判断の範囲

削除候補は外観・用途の重複を整理する提案です。「中」は残す判断も成立します。公開APIの参照、利用中のURL、エクスポートや既存利用者への影響は、実際に削除する段階で別途確認する必要があります。今回の調査ではアプリのパーツやコードを変更していません。
