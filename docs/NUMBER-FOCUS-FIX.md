# 数値入力の自動フォーカス修正

## 症状と原因

数値入力の＋／−ボタンを押すと、値変更の直後に中央の入力欄がフォーカスされ、フォーカス用の輪郭や素材表現がホバーのように現れていた。全20種類で共有する2つの数値コントローラーが、値の更新後に明示的な`input.focus()`を呼び出していた。

## 修正

通常版とWAYFINDER版の共有コントローラーから、自動フォーカスを外した。クリックで値を変えた後は操作した＋／−ボタンがフォーカスを保持し、直接入力するときは入力欄を利用者が選択する。範囲制限、未確定入力、IME処理、キーボード操作はそのまま維持する。

数値入力20種類すべての使い方とAI用プロンプトを更新した。共有コードは全形式・両配置の配布ソースにも含まれる。

## 確認

基礎コンポーネントのブラウザー回帰テスト内で、全20種類について＋／−による値の更新、押したボタンのフォーカス維持、入力欄への直接フォーカスが可能なことを確認する。型チェックとVite本番ビルドも実行する。
