## 新規16項目の内容

- A/B48スキンについて、単独・共通CSS一回・共通CSSの重複読込の計算スタイル一致。
- 可視レール9〜12px、つまみ15〜18px。34pxの独立操作領域。
- 8種類だけに進捗表現があること。.25と.75の位置変化。
- Magneticの変形レールが横方向LTR/RTLの実つまみと一致。
- Aの初期状態は大きな先頭アイコンなし。一般的な設定項目で選択可能。
- 任意のアイコンを指定すると20pxで表示できる。
- ホバー／キーボード候補と確定値を分離。面は候補に追従。
- 16候補・グループ付きの内部スクロールでも背景面がずれない。
- 長い文言・サイズ変更後の背景面再計測。文字のDOMを置換しない。
- 移動途中の面の位置を計測し、実際に補間していることを確認。候補の文字は動かない。
- ポインター追従と連続した候補移動で、古い確定処理を遅延実行しない。
- 幅320/390/768px、長い文言でページ・候補の横あふれがない。
- 粗いポインターでは44pxのレール操作領域、見えるレール幅は不変。
- reduced-motionで演出停止、forced-colorsで選択状態を維持。
- native選択・フォームリセット・無効状態を保持。
- 開閉／取り外し反復後にRAFとpopoverが残らない。

## 実際の環境と未実行項目

Linux、Node.js 22.16.0、TypeScript 5.8.3、システムのChromiumを使用しました。`SOP_TEST_MODE=offline`と`CHROMIUM_PATH=/usr/bin/chromium`を明示し、実ソースから作るテスト用バンドルをブラウザー文書へ読み込んでいます。DOMや操作を模したダミーのブラウザーではありませんが、ViteのHTTP配信ではありません。

この環境ではnpmレジストリへ接続できません。指定のVite、Playwright、React、型定義一式を取得したとは主張しません。CLI agent-browserも利用できなかったため、既設Playwrightから実Chromiumを操作しました。

**実Viteビルド・本番HTTP配信、指定Reactランタイムでの再実行、公式React/Vite/Node型定義を含む全体型チェック、npm audit、GitHub Actionsの完走は未確認です。** React TSX/JSXのソース変換と依存ファイル収集は単体テストに含みますが、Reactランタイム検証とは区別します。

Windows Explorer、実機iOS/Safari、Firefox、OSのクリップボード／ダウンロード先、実タッチ機器は未検証です。幅と粗いポインターの検証は、実機試験の代用ではありません。

## 再実行

通常環境:

```sh
npm install
npx playwright install chromium
npm run verify
npm run package
```

対象確認だけなら`npm run test:refinement`。標準では実Vite HTTPを使い、オフラインモードは明示指定したときだけ有効です。CIにもこのテストを追加しています。

## 配布確認

`scripts/package.ts`は出力後にZIPを読み直し、CRCと全ソースのSHA-256を照合します。別実装のPython zipfileでもCRC・全ファイルのSHA-256・大文字小文字を無視した名前の衝突・相対パスを検査しました。別フォルダーへ再展開し、564パーツ・25カテゴリを確認し、アプリの型チェックと対象15件の単体テストが成功しました。

ログは`docs/refinement-checks/`、ソース保持の一覧は同フォルダーの`preservation.json`です。パッケージに含まれる`RELEASE-MANIFEST.json`で収録ファイルを確認できます。CRC/SHA-256は内容の整合性確認であり、マルウェア判定や無警告の保証ではありません。
