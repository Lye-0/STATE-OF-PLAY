# v4.1.0 検証記録

対象は `STATE-OF-PLAY-v4.0.0-rebuilt-full-repository.zip` を元にした改訂版です。564パーツを収録し、171種類のAタイプを改訂しています。今回の検証と過去版の検証を混同しないため、結果をこの文書へ分離しています。

Atelierブラウザーテストは、以下を実際のDOM・CSS・入力イベントで確認します。

1. **全284スキンの単独表示と混在表示が一致**。主要要素の背景、輪郭、影、文字、表示状態等のcomputed styleを照合。
2. **171パーツ × 幅320/390/768px** でページと操作領域が横にはみ出さない。
3. **16素材のスライダー**：ネイティブキー操作、上下限、無効状態、つまみの配置。
4. **16素材の選択カード**：装飾がネイティブ入力のヒット領域を遮らない。
5. **16素材のタグ**：選択と削除の操作先が独立する。
6. **Aタイプの候補一覧・カレンダー・補足パネル**：幅320px内の配置と外側クリックで閉じる動作。
7. **全パンくず**：最初はメニューが閉じ、操作で開き、内容更新時にも閉じる。
8. **明るい素材のラベル**：暗い背景でも読み取れるよう、自身の不透明な下地を持つ。
9. **動きを減らす設定・強制配色**：装飾の連続アニメーションを止め、選択・フォーカス・キー操作を保つ。
10. **取り外し**：通知・ポップオーバーがトップレイヤーに残らない。

既存テストでは9,024通り（564パーツ × 4形式 × 2配置 × 2保存形式）のソース/テキストZIPの本文とメタデータも照合しています。素材のソースに対するコピー表示は通常の依存解決から生成され、専用の表示用偽コードは使用していません。

## 修正中に見つけて直したこと

- v4のカンマ区切りCSSで、2つ目以降のセレクターにルートが付かず、他パーツへ影響していました。113ファイル・737分岐をパーツ内に限定しました。
- 立体アイコンがラジオのヒット領域に重なったため、装飾のポインター透過とネイティブ入力の領域を修正しました。
- 狭い画面で金属の選択カードが3px横へ出る箇所を、上向きの微小な浮き上がりに変更しました。
- 明るい素材の独立ラベルへ明示的な背景色を追加しました。
- パンくずの遅延初期化メニューを、初回操作前には表示しないよう修正しました。

## 環境と未実施項目

今回の実行環境はLinux、Node.js 22.16.0、TypeScript 5.8.3、実Chromiumです。Playwrightは環境に用意されている `1.57.0-beta-1764944708000` をテスト実行時だけ使用しました。プロジェクトが指定するPlaywright 1.63.0へ依存設定を戻した/変更したという意味ではありません。

ブラウザーは管理ポリシーを変更せず、実ファイルのCSS・JavaScriptを `page.setContent` で読み込む **明示的なオフライン転送** で検証しました。DOM、コントローラー、CanvasではなくCSSの描画などは実装そのものです。モックDOMではありませんが、ViteサーバーによるHTTP配信確認とは異なります。

npmレジストリへの接続が利用できないため、**実Viteビルド、指定の公式React型定義を含む全体型チェック、指定React版での再実行、npm audit、GitHub Actions本番実行**は今回未実施です。Windows/Safari/Firefox実機も未検証です。`npm run verify` 全体が今回完走したという意味ではありません。

ログは `docs/atelier-checks/` に収録しています。116件の既存単体テストと8件の新規テストは別コマンドで実行しました（計124件）。通常環境では `npm test` で双方が実行されます。

## 再実行

```sh
npm install
npx playwright install chromium
npm run verify
npm run package
```

`npm run test:atelier` の通常モードはViteを起動して検証します。今回のオフライン環境変数は通常の開発には必要ありません。全体ZIPの最終再展開・CRC/SHA-256照合については `docs/atelier-checks/archive-check.json` を参照してください。ハッシュ一致は格納の整合性確認であり、安全性や全ブラウザー対応の保証ではありません。
