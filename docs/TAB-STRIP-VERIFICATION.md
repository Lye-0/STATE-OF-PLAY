# タブ部品の一時的な縦スクロールバー — 2026-09-23

## 原因と修正

横向きのタブ列は `overflow-x:auto` によって、縦方向のoverflowも自動計算されていました。選択面の変形中に内容が1px以上はみ出すと、タブ列に縦スクロールバーが一瞬現れます。実際にAtlas、Folio、Prism、Observatory、Ticketで確認しました。

共通スタイルで横向きタブ列の縦overflowを隠し、横方向のスクロールとキーボード操作は維持します。縦向きのタブ配置には適用しません。Ribbon Tabsは帯の装飾を枠外に出すためoverflowを表示するデザインで、混在時もその指定が維持されるようセレクターを調整しました。

部品の配布コードは正本 `src/shared/selection-base.css` から生成します。タブ用の使い方とAIプロンプトは共通生成処理で更新しました。詳細画面、ZIP、CLIが同じソース・説明・プロンプトを使います。

- 詳細画面のコード表示、コード込み・仕様のみのプロンプト、7項目への変更、横スクロールと縦向き切り替えを確認しました。

- アプリ・React・ツールのstrict型チェック、本番Viteビルドが成功しました。既存のタブ／セグメント検証も実Viteで完走し、48パーツの通常操作、レスポンシブ表示、キーボード操作、React TSX／JSXと両配置の操作・フォーム検証が成功しました。
