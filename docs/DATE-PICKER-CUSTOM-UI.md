# 日時選択の独自UI — v4.10.10

日時選択20種類（A13・B7）の入力欄がブラウザー標準の `date` / `datetime-local` / `time` だったため、装飾された日付選択ボタンとネイティブの選択ボタンが同時に見えていました。時刻だけのモードでは独自パネルが開かず、OSの時刻選択UIに依存していました。

共有の `src/shared/foundation/date-ui.ts` に値と操作の処理をまとめ、Aの `continuum/date.ts` とBの `date.ts` から使用します。表示欄はテキスト入力とし、日付・期間は独自カレンダー、時刻は24時間表記の時・分選択面を使います。`datetime` では一つのパネルに両方を表示します。Aの展開モーションと各パーツの配色、Bの簡素な表示は維持します。

| モード | 値 | パネル |
| --- | --- | --- |
| `date` | `YYYY-MM-DD` | 日付 |
| `range` | `[YYYY-MM-DD, YYYY-MM-DD]` | 開始・終了欄から同じ日付パネル |
| `datetime` | `YYYY-MM-DDTHH:mm` | 日付＋時・分 |
| `time` | `HH:mm` | 時・分 |

日付はローカル日付として扱い、UTCへの変換はしません。直接入力、選択不可日、`minDate` / `maxDate`、`name` によるFormData、外部制御、フォームリセット、`disabled` / `readOnly`、Escapeとキーボード操作に対応します。変更は20種類すべての`markup.html`、Vanillaデモ、React説明、使い方、AI用プロンプトへ反映し、配布時の共有TS/CSSも同じ実装を参照します。

確認には20種類×4モードのブラウザー検証、A/B両方の実操作、直接入力とFormData、詳細画面の表示と配布ソースの照合、型チェック、単体テスト、Viteビルドを使用します。実機OSすべての組み合わせでの表示確認は含みません。
